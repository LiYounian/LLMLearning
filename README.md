# LLMLearning

用一系列**可交互 HTML 网页**系统学习大模型。每条学习线独立成一个中文命名的顶层文件夹，配索引目录 + 分节详解 + 可交互 demo + 参考文献（一手来源可点击溯源）。纯静态，浏览器直接打开。

|---|---|---|---|
| **大模型基础课** | 分课讲基础理论。第一课：Tokenizer 原理（方法时间线式）；第二课：位置编码（规划中） | [`大模型基础课/第一课-Tokenizer/`](大模型基础课/第一课-Tokenizer/) | 第一课 v3 |
| **大模型演进路线** | 主流大模型（8 家）发展脉络站点 | [`大模型演进路线/`](大模型演进路线/) | v2（14 页 + 时间线公司泳道视图） |

## 快速开始

纯静态网页，无需起服务，直接用浏览器打开各学习线首页即可：

```bash
open 大模型基础课/第一课-Tokenizer/index.html
```

带交互动画的页面建议用本地静态服务打开以确保 JS 正常：

```bash
cd 大模型基础课/第一课-Tokenizer && python3 -m http.server 8791
# 浏览器访问 http://localhost:8791/index.html
```

## 第一课主线（Tokenizer）

> 词（word）→ 字符（char）→ 词片（subword：BPE/WordPiece/Unigram）→ 字节（byte-level BPE）→ 动态字节块（frontier）

核心结论：主流生成式大模型（GPT / Qwen / DeepSeek / Kimi K2）今天基本都用同一套 **字节级 BPE**，差异只在词表大小与预切分规则。详见 [第一课 README](大模型基础课/README.md)。
