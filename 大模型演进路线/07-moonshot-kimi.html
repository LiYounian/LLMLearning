月之暗面 Kimi 先闭源后开放权重

从"超长上下文"起家的国内头部大模型产品线，经历产品闭源期 → RL 推理期 → agentic 开放权重期三阶段。K2 是分水岭：首创 MuonClip 优化器稳定万亿级 MoE 训练，以近乎 MIT 的许可开放权重；K3 进一步放大到 2.8T 参数、100 万上下文，号称"史上最大开源权重模型"。

阅读说明 · 诚实边界
参数量 / 训练 token / 上下文长度以官方（技术报告、官方 GitHub/HuggingFace/博客）披露为准；官方未公开的一律标注"官方未公开"，不臆造。助手知识截止 2026-01，K2.5 及之后版本（K2.6 / K2.7 / K3）主要依赖二手来源核实，相关不确定性已在文末集中标注。产品期（2023–2024）底层模型参数与训练数据官方从未公开。

发展时间线

2023-10 · 产品期（闭源）

Kimi Chat（初代智能助手）

以"支持 20 万汉字输入"（维基折合约 128K tokens）作为核心卖点，号称全球首个支持 20 万汉字输入的 AI 产品。底层模型不开源、参数量与训练数据官方未公开。[1]

2024-03 · 产品期（闭源）

上下文扩容（内测）

无损上下文从 20 万汉字扩展到 200 万汉字（内测），长文本能力大幅升级。底层模型规模仍未公开。[1]

2025-01-20 · 推理期（技术报告公开）

Kimi k1.5

多模态 LLM + 强化学习。确立"用 RL 扩展 LLM 推理"路线：长上下文 RL（128K）+ 改进的策略优化，刻意不用 MCTS、价值函数、过程奖励模型（PRM），主打简洁有效，并做长思维链→短思维链蒸馏。对标 OpenAI o1。参数量与预训练 token 官方未公开。[2]

2025-04 / 2025-06 · 衍生开源

Kimi-VL（16B/3B 激活）· Kimi-Dev（72B）

轻量级开源多模态视觉语言模型 Kimi-VL，与面向 SWE-bench 类任务的代码专用模型 Kimi-Dev，标志权重开源的先行试水。训练细节多数未公开。[4]

2025-07 · Agentic / 开放权重期（分水岭）

Kimi K2（Instruct / Base）

稀疏 MoE，1.04T 总参 / 32B 激活（384 专家选 8 + 1 共享专家、61 层、MLA、词表 16 万）。首创 MuonClip 优化器（Muon + QK-Clip 防注意力 logit 爆炸），在 15.5T tokens 预训练中零 loss spike。明确定位 agentic，后训练用大规模 agentic 数据合成 + 联合 RL。以修改版 MIT 许可开放权重。[3][5]

2025-09-09 · 开放权重

Kimi K2-Instruct-0905

架构同 K2（1T/32B），上下文从 128K 翻倍到 256K，agentic / 前端编码能力增强，编码类基准提升。增量训练数据量官方未公开。[6]

2025-11-06 · 开放权重

Kimi K2 Thinking

MoE 推理变体（1T/32B，256K）。提出交错式思考（interleaved thinking）：在工具调用之间穿插推理步骤，支持 200–300 次连续工具调用无需人工干预。HLE(带工具) 44.9、BrowseComp 60.2、SWE-bench Verified 71.3。[7]

2026-01-27 · 开放权重（知识截止后，二手核实）

Kimi K2.5

原生多模态 MoE（1.04T/32B，384 专家选 8，MLA + SwiGLU，256K）。原生视觉+文本、引入 Agent Swarm 多智能体协同；续训约 15T 图文混合 tokens（二手口径）。HLE 50.2（Agent Swarm 模式，二手口径）。[8]

2026-04（约）· 开放权重（二手口径）

Kimi K2.6

MoE，编码 / agentic 进一步优化。SWE-bench Verified 80.2、LiveCodeBench v6 89.6（均为二手口径，未见一手技术报告）。参数量、上下文官方未公开。[9]

2026-07（约）· 开放权重（二手口径）

Kimi K2.7 Code

代码 / CLI agent 专用迭代。仅找到二手来源，编码基准未一手核实。发布月份与指标待一手核实。[10]

2026-07 · 开放权重（README 口径）

Kimi K3 —— 号称史上最大开源权重模型

超大 MoE，2.8T 总参 / 104B 激活（896 专家选 16、93 层 = 69 KDA + 24 Gated MLA、词表 16 万、MoonViT-V2 视觉编码器 401M）。上下文跃升至 100 万 tokens（1,048,576）。新术语：KDA & Gated MLA 注意力、Stable LatentMoE、SiTU-GLU、MXFP4/MXFP8 量化感知训练。GPQA-Diamond 93.5、BrowseComp 91.2、DeepSWE 67.5、Video-MME 90.0（官方 README 口径）。训练 token 总量 README 未列。[11]

核心技术标签

超长上下文 Muon / MuonClip 优化器 QK-Clip RL 推理（不用 MCTS/PRM） 交错式思考 agentic 数据合成 开放权重 多智能体 Agent Swarm

超长上下文（贯穿始终，最早的差异化标志）

初代 Kimi Chat（2023-10）以"支持 20 万汉字"作为核心卖点，是当时全球领先的长文本产品；2024-03 无损扩到 200 万汉字（内测）。到大模型层面：k1.5 的 RL 训练上下文 128K；K2 初版 128K，K2-Instruct-0905（2025-09）翻倍到 256K；K3（2026-07）跃升到 100 万 tokens。

Muon / MuonClip 优化器（K2 引入，稳定万亿级训练）

Muon 优化器（基于矩阵谱域正交化，Keller Jordan 等 2024 提出）由 Moonshot 在《Muon is Scalable for LLM Training》中推向大规模，约为 AdamW 的 2 倍算力效率。[12] Kimi K2 进一步提出 MuonClip：在 Muon 基础上引入 QK-Clip——主动重缩放 query/key 投影权重，防止 MoE 大模型训练中的注意力 logit 爆炸。效果是 K2 在 15.5T tokens 预训练中实现"零 loss spike / 零训练不稳定"，这是把 MoE 稳定放大到 1T 级的关键（此前 Adam 系在该尺度易发散/尖峰）。[3]

强化学习驱动的推理（k1.5 引入，K2 Thinking 深化）

Kimi k1.5（2025-01）确立"用 RL 扩展 LLM 推理"路线：长上下文 RL + 改进策略优化，刻意不用 MCTS、价值函数、PRM，主打简洁有效，同时做长→短思维链蒸馏，对标 OpenAI o1。Kimi K2 Thinking（2025-11）把推理与 agentic 融合，提出交错式思考：在工具调用之间穿插推理步骤，支持 200–300 次连续工具调用。

Agentic 与开源策略转向（K2 是分水岭）

K2（2025-07）明确定位为 agentic 模型（面向工具使用、推理、自主问题求解），后训练采用大规模 agentic 数据合成流水线 + 联合 RL。沿 K2 → K2-Instruct-0905（编码增强）→ K2 Thinking（长程工具调用）→ K2.5（Agent Swarm 多智能体协同）逐步强化。开源上：2023–2024 产品期闭源 → 2025-01 起技术报告公开、陆续开源 Kimi-VL/Kimi-Dev → K2（2025-07）以修改版 MIT 许可开放权重，此后 K2 Thinking、K2.5、K3 延续开放权重路线。

数据 / 规模

  • 初代 Kimi Chat / 2024 扩容：底层模型参数量、训练数据官方均未公开；对外仅给上下文口径（20 万→200 万汉字）。
  • Kimi k1.5（2025-01）：多模态数据配方 + RL，预训练 token 量、参数量官方未公开；已知 RL 上下文 128K。
  • 衍生开源模型：Kimi-VL 16B（3B 激活）；Kimi-Dev 72B。
  • Kimi K2（2025-07）：总参 1.04T、激活 32B；384 专家选 8 + 1 共享专家、61 层、词表 16 万、MLA；预训练 15.5T tokens（零 loss spike）。
  • K2-Instruct-0905（2025-09）：架构同 K2，上下文 128K→256K；增量训练数据量官方未公开。
  • Kimi K2.5（2026-01）：1.04T/32B，384 专家选 8，MLA+SwiGLU；续训约 15T 图文混合 tokens（二手口径）。
  • Kimi K3（2026-07）：总参 2.8T、激活 104B、896 专家选 16、93 层（69 KDA + 24 Gated MLA）、词表 16 万、MoonViT-V2 视觉编码器（401M）；训练 token 总量官方 README 未列。
规模走势
参数：产品期未公开 → K2 首次给出精确规模（1.04T/32B）→ K3 放大到 2.8T/104B。上下文：128K → 256K → 1M。

对比须谨慎
编码 agentic 指标（SWE-bench Verified）从 K2 的 65.8 → K2 Thinking 71.3 → K2.6 约 80.2 稳步上行；知识/检索类（GPQA、BrowseComp）在 K3 大幅拉高。但跨代基准的版本、是否"带工具/思考模式"不同，纵向数字不宜直接相减比较。K2 Thinking 之后的指标多为二手口径。

不确定与空白（诚实标注）

  • 初代上下文口径："20 万汉字"是官方营销口径，维基折算约 128K tokens，两者非同一单位；底层模型参数量/训练数据官方从未公开。
  • k1.5 规模未公开：只公开 RL/多模态方法与基准，未公开参数量、预训练 token 总量。
  • K2 参数写法：技术报告为 1.04T 总参 / 32B 激活；部分材料简写为"1T"，指同一模型（HuggingFace 卡片写"1T"）。
  • K2 Thinking 上下文：多数二手来源写 256K，但未见一手技术报告明确该数值，存在口径不一风险。
  • K2.5 / K2.6 / K2.7 属知识截止后（2026）：K2.5 有官方页与 arXiv 2602.02276，但"Agent Swarm""HLE 50.2"等来自二手/宣传，未逐条一手复核；K2.6 / K2.7 仅二手来源，发布月份与指标待一手核实。
  • Kimi K3 细节需谨慎：发布日期口径冲突（维基 2026-07-16，多家媒体 07-26/27，本文取 2026-07）；架构新术语（KDA、Gated MLA、SiTU-GLU、Stable LatentMoE、MoonViT-V2、MXFP4/MXFP8）来自 README 抓取，属知识截止后新术语，无法用既有知识交叉验证；参数 2.8T/104B、896 专家选 16、100 万上下文在维基与多家媒体间一致性较高；训练 token 总量与数据构成 README 未列。
  • 竞品对比慎用：部分二手来源出现的竞品名与排名，本文未采信为事实。
