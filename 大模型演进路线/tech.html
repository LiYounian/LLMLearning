技术脉络（横向专题 T1–T8）

把 8 家的技术按主题横向串起来——这也是后续可逐点深挖的技术清单。每条都标注"谁首创/谁代表"。

T1 · 基座架构：从"标准配方"到"稀疏注意力"

  • Transformer decoder-only（2017/2018）：全家共同起点。
  • 标准配方组件：Pre-norm + RMSNorm、RoPE 旋转位置编码、SwiGLU 激活——Llama 1（2023）定型，Qwen/DeepSeek/Kimi 普遍沿用。
  • GQA 分组查询注意力：Llama 2 / Qwen2 引入，降 KV cache、加速长序列。
  • MLA 多头潜在注意力：DeepSeek V2（2024）首创，KV cache 降约 93%，是低成本长文本的关键。
  • 稀疏注意力：DeepSeek DSA（2025）把 O(L²)→O(L·k)；Llama 4 iRoPE；Kimi K3 KDA/Gated MLA——2025-26 长上下文提效的新前沿。

T2 · 稀疏化 MoE：从 dense 到万亿总参

  • 代表落地：Gemini 1.5 与 DeepSeek V2（均 2024）把 MoE 推成主流；随后 Qwen3、Llama 4、Kimi K2、豆包全线 MoE。
  • 关键工程：DeepSeek 无辅助损失负载均衡（V3）、Qwen upcycling（从 dense 回收）、豆包训推一体（性价比杠杆约 7×）。
  • 规模：激活参数与总参数解耦——DeepSeek V3 671B/37B、Kimi K2 1.04T/32B、Qwen3.8-Max 2.4T/95B、Kimi K3 2.8T/104B。

T3 · 对齐 / 后训练：RLHF → RLAIF → DPO → GRPO

  • RLHF（SFT+奖励模型+PPO）：OpenAI InstructGPT（2022）首次系统化，把语言模型变对话助手；Llama 2-Chat 开源复现。
  • Constitutional AI + RLAIF：Anthropic（2022）用"宪法"让 AI 自我批评、用 AI 反馈替代大量人工标注。
  • DPO：Llama 3 等采用，简化偏好优化（去掉显式奖励模型与 PPO）。
  • GRPO：DeepSeek DeepSeekMath（2024）首创，去 critic 的组相对优势估计，后成为 R1 纯 RL 推理的核心。

T4 · 推理模型 / test-time compute（2024 起最大范式）

  • o1（OpenAI 2024）：首个大规模推理模型——回答前用私有 CoT"思考"，把算力从训练转向推理期。
  • DeepSeek R1（2025）：纯 RL（GRPO）激发推理，R1-Zero 不用 SFT 冷启动即涌现"aha moment"；开源开放，登 Nature，影响巨大。
  • thinking 显式化/可切换：Claude 3.7 extended thinking → Gemini 2.5 Deep Think（并行思考）→ Qwen3 thinking/非-thinking 统一 + thinking budget → DeepSeek V3.1 混合推理。
  • 档位化成本控制：Claude effort 参数、Qwen/OpenAI reasoning_effort（xhigh/medium/low）——把"思考多深"变成可调旋钮。

T5 · 长上下文：从 100K 到 1M+

  • 产品先声：Kimi Chat（2023）以 20 万→200 万汉字打差异化。
  • 技术推进：Claude 200K → Gemini 1.5（2024）1M~10M → Qwen2.5-1M → 2026 普遍 1M（Claude / DeepSeek V4 / Qwen Max / Kimi K3）。
  • 方法演进：RoPE 外推 / YARN / DCA → MLA / DSA 原生长上下文 + 稀疏注意力。

T6 · 多模态 / 全模态

  • 图像输入：GPT-4（2023）→ Claude 3（2024）。
  • 原生多模态：Gemini 1.0（2023）从预训练即联合多模态；GPT-4o（omni）；Llama 4 early fusion；Qwen-VL/Omni；豆包全模态。
  • 全模态统一（文/图/音/视频）：Qwen Omni（Thinker-Talker）、豆包 Seed-2.0-lite、GPT-4o。
  • 视觉作为反馈回路：2026 旗舰用"生成→观察→修正"把视觉纳入 agent 执行闭环。

T7 · Agentic（2025-26 行业主线）

  • computer use / GUI Agent：Claude（2024-10）首个前沿模型公测；字节 UI-TARS 独立研究线。
  • 工具调用 + 长程自主：Kimi K2（agentic 数据合成 + 联合 RL）、K2 Thinking（200-300 次连续工具调用）；Qwen Max（数天级自主编程/办公）；Claude agent teams。
  • agentic RL 训练：真实环境×算力联合扩展 + 统一奖励系统。

T8 · 训练/推理效率工程

  • FP8 训练：DeepSeek V3。
  • MuonClip 优化器：Kimi K2（QK-Clip 稳定万亿 MoE 训练，零 loss spike）。
  • 训推一体 + 极致降本：豆包；DeepSeek 低成本训练。
  • token 效率：GPT-5.6、Gemini 3.6 Flash（"用更少 token 达到更高智能"）。
