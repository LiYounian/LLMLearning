Anthropic Claude 闭源

Anthropic 的旗舰大模型家族，2023 年 3 月首发。核心特征是"安全优先"的训练范式——Constitutional AI（宪法式 AI）+ RLAIF（基于 AI 反馈的强化学习），目标是 helpful, honest, harmless（有用、诚实、无害）。从长上下文到多模态视觉、计算机操作、扩展思考与 agentic 工具栈，Claude 一路把"能干活的助手"推向"能自主完成长时程任务的 agent"。

阅读前须知：参数量与训练数据一律"官方未公开"
Anthropic 从未公开任何一代 Claude 的参数量与训练数据 token 量，本页所有此类字段一律如实标注"官方未公开"，绝不臆造。基准分数中，官方 model card 公布的与第三方评测/聚合站点的分数会分别注明——同名基准跨来源常有 1–5 个百分点差异（评测子集/脚手架不同），引用时务必点明口径。调研截止 2026-08-03。

发展时间线

演进主线（命名与时间已联网核实）：Claude 1/2 奠基 → Claude 3 首次三档分级 + 视觉 → 3.5 加 Artifacts 与计算机操作 → 3.7 引入扩展思考/混合推理 → Claude 4 系列铺开 agentic 工具与 1M 上下文 → 2026 的 Claude 5 家族（Sonnet 5 / Opus 5 / Fable 5 / Mythos 5）。注意"Claude 5"是家族称谓而非单一模型；Opus 仍有 4.x 与 5 并存，Haiku 停在 4.5 档。

2023-03-14

Claude 1 / Claude Instant

仅文本 Transformer（GPT 式）。首发即落地 Constitutional AI + RLAIF。早期上下文约 9K（该数字来源可靠性一般，属细节存疑项）。参数量·训练数据：官方未公开。

2023-07-11

Claude 2

公开上线 claude.ai，编码/数学提升。上下文扩到 100K，长文档一次性阅读成为卖点。

2023-11-21

Claude 2.1

上下文提升到 200K；引入 tool use；官方称幻觉较 2.0 减半。200K 此后成为 Claude 3/4 的主流窗口。

2024-03-04 / 03-13

Claude 3（Opus / Sonnet / Haiku）

首次把家族拆成三档并加入视觉输入（多模态文+图）。Opus 官方 model card：MMLU 86.8%、GPQA 50.4%、GSM8K 95.0%。上下文 200K。（Opus/Sonnet 3-04 发布，Haiku 3-13）

2024-06-20

Claude 3.5 Sonnet

推出 Artifacts（对话旁生成可交互工件）；中档模型即超越上一代 Opus。第三方汇总：SWE-bench Verified 33.4%、GPQA Diamond 59.4%、HumanEval 92.0%。

2024-10-22

Claude 3.5 Sonnet（升级版）+ 3.5 Haiku

首个前沿模型公测 computer use 计算机操作——像人一样看屏幕、移动光标、点击、输入，为 agentic 工作流铺路。SWE-bench Verified 升至 49.0%（第三方汇总）。

2025-02-24

Claude 3.7 Sonnet

首个混合推理模型：同一模型可"近即时回答"或"先产出扩展思考（extended thinking）再作答"，思考步数可控。同时发布 Claude Code。SWE-bench Verified ~62.3%（官方口径）。

2025-05-22

Claude Opus 4 / Sonnet 4

铺开 agentic 工具栈：code execution 沙箱、MCP 连接器、Files API。Sonnet 4 后提供 1M 上下文 beta；Opus 4 首次触发 ASL-3 安全等级。官方：Opus 4 SWE-bench 72.5% / Sonnet 4 72.7%。

2025-08-05

Claude Opus 4.1

编码 / agent 能力增量提升。上下文 200K。

2025-09-29

Claude Sonnet 4.5

主打长时程 agent，发布时为最强编码 Sonnet；上下文 200K / 1M。官方称"the best coding model in the world"，SWE-bench Verified 领先同档。

2025-10-15

Claude Haiku 4.5

低成本小模型，性能接近上一代前沿。上下文仍 200K（最大输出 64K）。此后 Haiku 停留在 4.5 档。

2025-11-24

Claude Opus 4.5

引入 effort 参数与 Infinite Chats。定价 $5/$25 每百万 token。第三方汇总：SWE-bench Verified 80.9%、GPQA Diamond 87.0%、MMLU 90.8%、Terminal-bench 59.3%。

2026-02-05 / 02-17

Claude Opus 4.6 / Sonnet 4.6

adaptive thinking 自适应思考（模型自行决定思考深度）、effort GA、agent teams。1M 上下文成为标配起点。Sonnet 4.6 SWE-bench Pro ~58.1%。

2026-04-16

Claude Opus 4.7

换用新分词器；引入高分辨率视觉（长边 2576px）与 task budgets（任务级 token 预算）。SWE-bench Pro ~64.3%（第三方汇总）。

2026-05-28

Claude Opus 4.8

支持会话中途注入 system 消息、fast mode。官方称领先当时多数榜单：SWE-bench Verified 88.6%、SWE-bench Pro 69.2%、Online-Mind2Web 84%、HLE 49.8%（无工具）/ 57.9%（带工具）。

2026-06-09

Claude Fable 5 / Mythos 5（Mythos-class 顶配）

思考常开（always-on），原始思考链永不返回。内置更强网络/生物安全分类器：命中以 HTTP 200 + stop_reason:"refusal" 返回，可配置服务端 fallback 降级到 Opus 4.8 作答。Fable 5 SWE-bench Verified ~95%、SWE-bench Pro 80.3%（第三方汇总）。曾因出口管制于 2026-06-12 短暂下线、07-01 恢复。Mythos 5 仅限 Project Glasswing 受邀访问。

2026-06-30

Claude Sonnet 5

默认自适应思考；新分词器。SWE-bench Pro ~63.2%（第三方汇总）。

2026-07-24

Claude Opus 5

思考默认开启；定价 25/百万 token 档，512-token 缓存下限。第三方博客称 SWE-bench Verified ~97%、GPQA Diamond ~94.1（未见官方 model card，谨慎引用）。

核心技术标签

Constitutional AI + RLAIF 奠基技术

源自 Anthropic 论文《Constitutional AI: Harmlessness from AI Feedback》（2022-12-15）。核心：用一份"宪法"（一组原则/准则）让模型对自身输出做自我批评与修订，再用 AI 反馈替代大量人工标注做强化学习（即 RLAIF），在不依赖昂贵人工的情况下让模型更无害。解决的是"可扩展对齐"——降低对人工偏好标注的依赖，同时提升诚实/无害性。宪法本身持续扩充：2023 年约 2,700 字 / 75 条准则 → 2026 年约 23,000 字。此技术自 Claude 1/2 起贯穿至今。

长上下文 规模代理

Claude 2 = 100K，Claude 2.1 = 200K，解决法律/金融/科研长文档一次性阅读问题。200K 一直是 Claude 3/4 主流窗口，直到 2026 年 Opus 4.6+ / Sonnet 5 / Fable 5 / Opus 5 把 1M 定为标配（Haiku 4.5 仍 200K）。由于参数量从不公开，上下文窗口是唯一可确证的"规模"信息。

多模态视觉与三档分级 Claude 3

2024.03 首次支持图像输入，并首次把家族拆成 Haiku（快/省）/ Sonnet（均衡）/ Opus（最强）。Opus 4.7 起进一步引入高分辨率视觉（长边 2576px）。分档即规模代理：Anthropic 用能力/价格分层间接反映规模差异，但不给绝对数字。

Artifacts 与 Computer use 产品化能力

Artifacts（3.5 Sonnet，2024.06）：在对话旁生成可交互的代码/文档工件。Computer use 计算机操作（升级版 3.5 Sonnet，2024.10）：首个前沿模型公测"像人一样看屏幕、移动光标、点击、输入"，为 agentic 工作流奠基。

扩展思考 → 自适应思考 推理范式

Extended thinking / 混合推理（3.7 Sonnet，2025.02）：同一模型可"近即时回答"或"先产出推理 token 再作答"。此后演进为 adaptive thinking 自适应思考（4.6 起）——模型自行决定思考深度，并用 effort 参数（low/medium/high/xhigh/max）控制"思考+行动"的总开销；固定 budget_tokens 预算被弃用。Fable 5 更是"思考常开且原始思考链永不返回"。

Agentic 工具栈与安全机制 Claude 4+

Claude 4（2025.05）起铺开 code execution 服务端沙箱、MCP（Model Context Protocol）连接器、Files API，配合长时程 agent 能力；4.7/4.8 又加 task budgets、fast mode、会话中途注入 system 消息。2026 顶配 Mythos-class 模型内置更强的网络/生物安全分类器，命中会以 stop_reason:"refusal" 返回拒答，并可配置服务端 fallback 自动改由 Opus 4.8 等模型作答。

数据 / 规模

参数量：全系列官方未公开
Claude 从未公开任何一代的参数量。外界仅有非官方推测，本页不采信也不臆造。任何声称具体参数量的第三方均为推测。
训练数据量：官方未公开
token 数 / 语料构成同样从未公开。官方仅泛泛描述为"在大规模文本（Claude 3 起含图像）上预训练的生成式预训练 Transformer，再经 RLHF + Constitutional AI 微调"。
唯一可确证的"规模"信息：上下文窗口
9K（早期）→ 100K（Claude 2）→ 200K（Claude 2.1 至 Claude 4 主流）→ 1M（2026 Opus 4.6/4.7/4.8、Sonnet 5、Fable 5、Opus 5；Haiku 4.5 仍 200K）。最大输出：Claude 4+ 多为 128K（Haiku 4.5 为 64K）。

分档即规模代理：Haiku < Sonnet < Opus < Fable/Mythos（Mythos-class 顶配）。Anthropic 用能力/价格分层间接反映规模差异，但始终不给绝对数字。
