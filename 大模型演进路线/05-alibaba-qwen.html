阿里 Qwen 开放权重为主

通义千问（Qwen）——目前开源社区影响力最大的中文系大模型家族。从"追赶开源基线"到"全尺寸覆盖 + 长上下文"，再到"thinking/非-thinking 统一 + thinking budget"，最后走向"能自主干活的 Agent"。

Qwen 由阿里巴巴（阿里云 / 通义实验室）自 2023 年起推出，涵盖语言模型主线、旗舰闭源 Max 线、多模态视觉线（VL）与全模态线（Omni）四条并行脉络。其显著特征是几乎全尺寸开放权重（0.5B 到 235B），叠加详实的 arXiv 技术报告，使其成为学术界与开发者复现、微调、二次开发的首选中文基座之一。

阅读须知：一手 vs 二手
Qwen 语言主线（Qwen1 → Qwen3）与多模态线（VL / Omni）均有独立 arXiv 技术报告，属一手可复现来源。2026 年的 Max 系列（3.5 / 3.7 / 3.8-Max）没有独立技术报告，仅有官方博客 / 发布公告；其参数、训练数据、跑分多为官方自评 + 自建内部基准，横向可比性存疑，本页对这部分统一按"厂商发布材料"打折看待，并显式标注"官方未公开"。

发展时间线

2023-08 · Qwen-VL

多模态视觉线开端

基于 Qwen-7B 的视觉-语言模型，主打图文理解、定位（grounding）、文字识别，当期多项 VL benchmark 达 SOTA。arXiv 2308.12966

2023-09 · Qwen（初代）

语言主线起点：标准配方

Dense 架构 1.8B / 7B / 14B / 72B，采用当期主流配置 RoPE + SwiGLU + RMSNorm + QKV bias；约 3T tokens 多语言（中英为主）；SFT + RLHF 出 Qwen-Chat，衍生 Code-Qwen / Math-Qwen。72B 对标 LLaMA2-70B，位列同尺寸开源第一梯队。arXiv 2309.16609

2024-02 · Qwen1.5

全系 32K + 首次上 MoE

0.5B~110B 全尺寸统一 32K 上下文，对齐与多语言增强；首次推出 MoE（A2.7B 激活）作为试水。72B / 110B 对标当期开源旗舰。Qwen1.5 官方博客

2024-06 · Qwen2

GQA + 长上下文外推 + MoE upcycling

Dense（0.5B/1.5B/7B/72B）+ MoE（57B-A14B）。引入 GQA 降低推理显存；长上下文用 YARN + Dual Chunk Attention 外推到 128K；MoE 走 upcycling（从 dense 权重回收再训 +4.5T tokens）。Dense >7T tokens（0.5B 用 12T）。72B-Instruct 多榜领先同期开源。arXiv 2407.10671

2024-08 · Qwen2-VL

任意分辨率 + M-RoPE

2B / 7B / 72B。Naive Dynamic Resolution 支持任意分辨率图像映射为可变数量视觉 token；M-RoPE 统一处理文本/图像/视频的位置。图文与视频理解当期 SOTA。arXiv 2409.12191

2024-09 · Qwen2.5

数据大扩容到 18T，旗舰开源标杆

0.5B~72B，另有 Coder / Math 专项。预训练数据从 Qwen2 的 7T 扩容到 18T tokens；后训练用约 100 万样本做 SFT + DPO + GRPO。最高 128K 上下文、输出 8K。72B-Instruct 以更小参数逼近当期部分闭源旗舰。arXiv 2412.15115

2025-01 · Qwen2.5-1M / Qwen2.5-Max / Qwen2.5-VL

首次 1M 上下文 + Max 线开端

Qwen2.5-1M（7B/14B）：长上下文训练 + 长度外推 + 推理加速，首次到 1M，长文检索（passkey 等）领先。arXiv 2501.15383
Qwen2.5-Max（MoE）：大规模 MoE 旗舰，>20T tokens + SFT/RLHF，官方称对标并部分超越 DeepSeek-V3；总参/激活参数官方未公开（网传 325B 未证实，不采信）。Qwen2.5-Max 博客
Qwen2.5-VL（3B/7B/72B）：动态分辨率 + 绝对时间编码，文档解析 / Agent 视觉，文档与视频 grounding 当期 SOTA。arXiv 2502.13923

2025-03 · Qwen2.5-Omni

全模态 Thinker-Talker

7B 全模态模型，统一文本/图像/音频/视频输入，Thinker-Talker 架构实现实时语音生成。全模态 benchmark 当期 SOTA。arXiv 2503.20215

2025-04 · Qwen3

thinking/非-thinking 统一 + thinking budget

标志性一代。Dense（0.6B~32B）+ MoE（30B-A3B / 235B-A22B）。把"深度推理（thinking）"与"快速响应（非-thinking）"统一进同一个模型，用户可切换，并引入 thinking budget（按任务难度动态分配推理 token 数）；强弱模型间知识蒸馏。36T tokens、119 种语言，三阶段预训练。235B-A22B 对标当期顶尖开源 / 部分闭源。arXiv 2505.09388

2025-09 · Qwen3-Max / Qwen3-Omni

Max 破万亿 + 全模态 MoE 低延迟

Qwen3-Max（MoE）：官方称"超万亿"参数（>1T），约 36T tokens，超越 Qwen3-235B-A22B-2507；无独立技术报告。Qwen 官方 X / Wikipedia
Qwen3-Omni（Thinker-Talker MoE）：全模态无损统一 + 显式 Thinking 推理，端到端首包延迟低至 234ms；36 项音频/音视频基准中 32 项开源 SOTA。arXiv 2509.17765

2025-11 · Qwen3-VL

原生 256K + 纯文本能力反超

Dense（2B~32B）+ MoE（30B-A3B / 235B-A22B），原生 256K 上下文。interleaved-MRoPE、DeepStack、文本时间对齐；纯文本能力反超同级文本模型。MMMU / 视觉数学等领先。arXiv 2511.21631

2026-02 · Qwen3.5 / Qwen3.5-Plus

新一代架构基座（开权重）

MoE 新架构基座，Qwen3.8-Max 即基于此架构；Qwen3.5 开权重。Wikipedia 称约 397B-A17B（二手，未见官方报告确认）；无独立 arXiv 技术报告。Wikipedia

2026-05 · Qwen3.7-Max

Agent 长程执行（闭源）

MoE 闭源，1M 上下文；主打 Agent 长程执行（宣称 30 小时+持续有效推进）。参数与训练数据官方未公开。Wikipedia / Yotta Labs（二手）

2026-08 · Qwen3.8-Max

首个开权重的 Max：2.4T / 95B-active

基于 Qwen3.5 架构的 MoE，2.4T 总参 / 95B 激活，1M 上下文。引入 reasoning_effort 三档（xhigh / medium / low）作为并发场景的"成本旋钮"，原生多模态，是首个开权重的 Max。官方自评：Terminal Bench 86.6 / PaperBench 93.0；E-Commerce Bench 4.16× 回报。精确 token 量官方未公开。Qwen3.8 官方博客

核心技术标签

标准配方 RoPE/SwiGLU/RMSNorm GQA 分组查询注意力 YARN + DCA 长上下文外推 MoE upcycling（dense 权重回收） MoE 主线化 235B-A22B thinking / 非-thinking 统一 thinking budget 思考预算 reasoning_effort 三档 VL 动态分辨率 M-RoPE / interleaved-MRoPE Omni Thinker-Talker 原生长上下文训练 → 1M

架构基线（Qwen1 → Qwen2）

Qwen1 采用当期 Transformer 主流配置：RoPE、SwiGLU、RMSNorm、QKV bias。Qwen2 引入 GQA（分组查询注意力）降低推理显存占用；长上下文用 YARN + Dual Chunk Attention 外推到 128K。

MoE 的引入与主线化

首次 MoE 是 Qwen1.5-MoE（A2.7B 激活）的试水；Qwen2 出 57B-A14B，用 upcycling（从 dense 权重回收再训 +4.5T tokens）而非从零训练；Qwen3 把 MoE 做成主线旗舰（235B-A22B / 30B-A3B）；Max 线全部走 MoE 并把规模推到极致（Qwen3-Max >1T，Qwen3.8-Max 2.4T/95B-active）。核心动机：在可控推理成本下继续放大总参数以提升能力上限。

thinking / 非-thinking 统一 + thinking budget（Qwen3 起）

Qwen3 的标志性创新是把"深度推理"与"快速响应"统一进同一模型并允许切换，并引入 thinking budget——按任务难度动态分配推理 token 数。2026 Max 线把这一思路产品化为 reasoning_effort 三档（xhigh/medium/low）+ preserve_thinking，成为高并发场景下平衡质量与成本的"旋钮"。

长上下文演进

Qwen1 8K（部分 32K）→ Qwen1.5 全系 32K → Qwen2/2.5 到 128K → Qwen2.5-1M 首次 1M → Qwen3-VL 原生 256K → Max 线（3.7/3.8-Max）1M。方法上从 YARN / DCA 外推，逐步走向原生长上下文训练。

多模态线

VL（视觉）：Qwen-VL → Qwen2-VL 的 Naive Dynamic Resolution + M-RoPE → Qwen2.5-VL 绝对时间编码 / 文档 Agent → Qwen3-VL 的 interleaved-MRoPE + DeepStack + 文本时间对齐。
Omni（全模态）：Qwen2.5-Omni → Qwen3-Omni 的 Thinker-Talker MoE 架构，统一文本/图像/音频/视频且各模态不掉点，端到端首包延迟低至 234ms。

从"答题"到"Agent 自主交付"（2026）

2026 Max 系列训练重心转向 agentic RL：官方称用"环境数×算力联合扩展 + 统一奖励系统 + 在线数据均衡器"，主打数天级自主编程、办公、长程任务。方法层面官方仅给理念、无可复现细节。

数据 / 规模

规模主线一句话：3T（2023）→ 7T（2024.06）→ 18T（2024.09）→ 20T+（Max）→ 36T（2025），预训练数据量约 2 年增长约 12 倍；参数侧从 72B dense（2023）走到 2.4T / 95B-active MoE（2026）。
