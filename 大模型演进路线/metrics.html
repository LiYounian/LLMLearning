指标脉络：评测范式的三次迁移

一个 benchmark 被刷到 90%+ 就换更难的——分数上升既反映真实进步，也反映"评测军备竞赛"。看懂这条线，才不会被单个跑分误导。

① 评测范式的三次迁移

2020–2024
知识 / 通识
主榜 MMLU，饱和后淡出
2024–2025
科学 / 数学推理
GPQA / AIME / ARC-AGI
2025–2026
真实任务 / Agentic
SWE-bench / Terminal / HLE
  1. 知识/通识时代（2020–2024）：主榜 MMLU。GPT-3 43.9% → GPT-4 86% → Gemini 1.0 Ultra / Claude Opus 4.5 ~90%，趋于饱和后被淡出主推。
  2. 科学/数学推理时代（2024–2025）：换用更难的 GPQA Diamond（研究生科学）、AIME/MATH（竞赛数学）、ARC-AGI（抽象推理）。GPQA Diamond 从 Claude 3 Opus 50% → 2026 前沿 92%+；AIME 从 <50% → 90%+；推理模型（o1/R1/Deep Think）是主要推手。
  3. 真实任务/Agentic 时代（2025–2026）：换用 SWE-bench (Verified/Pro)（编码 agent）、Terminal-Bench / OSWorld / RecreationBench（长程/GUI/经营）、HLE（Humanity's Last Exam）（极难综合）。SWE-bench Verified 从 Claude 3.5 的 33% → 2026 的 95%+。

🚩 读指标的三条警惕（分享时务必提醒）
  • 口径不一：是否带工具、thinking 档位、shot 数、评测脚手架不同，跨来源同名基准常差数个百分点，不可直接相减。
  • 自评与内部基准：2026 各家发布材料含大量"官方自评 + 自建内部基准"（尤其闭源旗舰与豆包/Qwen Max），第三方独立复核常缺位。
  • 饱和后换榜：一个榜被刷到 90%+ 就换更难的——分数上升既反映真实进步，也反映评测军备竞赛。
