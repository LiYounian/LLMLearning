Google Gemini 闭源

从 PaLM 到 Gemini 3——Google DeepMind 的旗舰谱系：原生多模态、稀疏 MoE、百万级长上下文、Agentic 智能体、Deep Think 显式推理五条技术主线的接力演进。

阅读须知 · 关于"未公开"
调研截止 2026-08。本谱系中唯一官方公开完整参数量 + 训练 token 的旗舰模型是 PaLM（540B / 780B tokens）；Gemini 全系旗舰档（Ultra / Pro / Flash）的参数量、训练 token、训练算力 Google 一律未公开，仅端侧 Nano（1.8B / 3.25B）有官方数字。凡传闻/媒体报道的数字均已在下文明确标注，请勿当作官方口径。

发展时间线

命名规律：每代通常含 Ultra / Pro / Flash / Flash-Lite / Nano 等档位——Ultra 最强、Nano 端侧、Flash 系列主打高性价比 / 低延迟。下方时间线聚焦每一代的架构转折与标志技术。

2022-04 · 前身阶段

PaLM (540B)[1][2]

稠密 decoder-only Transformer，Google Research 用 Pathways 系统在 6144 块 TPU v4 上训练。540B 参数、780B tokens（网页/书籍/维基/新闻/代码/对话），另有 8B/62B 档。引入 SwiGLU、并行层、多查询注意力。上下文 2,048 token。29 项 NLP 任务中 28 项超越同期模型，验证了大规模稠密模型的 few-shot 与 BIG-bench 突破性能力。

2023-05 · 前身阶段

PaLM 2 (Gecko / Otter / Bison / Unicorn)[3][4]

稠密 Transformer，混合训练目标。转向"计算最优缩放"（数据∶模型 ≈ 1:1）、更高比例多语种数据。官方刻意不再披露参数量与训练量；CNBC 援引内部文件传闻 PaLM 2-L 约 340B 参数、约 3.6T tokens（媒体报道，未经 Google 官方确认）。是 Bard 早期及 Med-PaLM 2、Codey 等衍生模型的底座。

2023-12 · Gemini 阶段开启

Gemini 1.0 (Ultra / Pro / Nano)[6][7]

Google DeepMind 主导。首个从预训练第一步就原生多模态（文本+图像+音频+视频联合训练，而非后期拼接）的旗舰。TPU v4/v5e 训练，上下文 32,768 token。Nano-1 = 1.8B、Nano-2 = 3.25B（端侧、蒸馏+4bit 量化，官方唯一公开数字）；Ultra/Pro 参数未公开。Ultra 在 32 项基准中 30 项 SOTA，MMLU 90.0%（CoT@32）——首个越过"人类专家 ~89.8%"阈值。

2024-02 · 架构转折

Gemini 1.5 Pro[8][9]

引入稀疏 MoE（每次推理仅激活部分专家，总参数可增大而单次算力近似恒定）+ 超长上下文：标准 128K、面向部分用户 100 万、研究中验证到 1000 万 token。跨百万 token 多模态检索近乎完美（1M 时 99.7% recall，10M 时 99.2%）。参数官方未公开。

2024-05

Gemini 1.5 Flash[9]

蒸馏自 1.5 Pro 的轻量 MoE，面向高频 / 低延迟场景。保留 100 万 token 长上下文能力，速度大幅提升。参数未公开。

2024-12 · Agentic 时代

Gemini 2.0 (Flash 实验版 → Flash / Flash-Lite / Pro)[10][11]

原生多模态 MoE，定位"智能体（Agentic）时代"：原生工具调用（Google 搜索、代码执行、地图、第三方函数），并能在一次 API 调用中生成文本+图像+音频混合输出。2.0 Flash 速度约为 1.5 Pro 两倍且性能更强。上下文 100 万 token（Flash）。参数未公开。

2025-06 · 显式推理

Gemini 2.5 Pro / Flash (GA)[12][13][14]

原生多模态 MoE 内置 "thinking" 显式推理。旗舰 2.5 Pro Deep Think 采用"并行思考"（同时生成并互相批判多个假设再作答，研究版达 2025 IMO 金牌水平）。GPQA Diamond 84.0%（Pro）；Deep Think MMLU-Pro 89.8%、GPQA 82.4%。上下文 100 万（规划扩到 200 万）。参数未公开。

2025-07

Gemini 2.5 Flash-Lite[15]

轻量 MoE，最低成本 / 最低延迟档，面向大规模低成本部署。上下文 100 万 token。参数未公开。

2025-11 · 推理优先

Gemini 3 Pro (+ 3 Deep Think)[16][17][18]

推理优先设计的原生多模态 MoE；新增像素级指向的零样本视觉检测，Deep Think 强化多步推理。Humanity's Last Exam 37.5%（无工具）；GPQA Diamond 91.9%；AIME 2025 95%；ARC-AGI-2 31.1%；LMArena 榜首 1501 Elo。上下文 100 万 token。参数未公开。

2026-02

Gemini 3.1 Pro (Preview)[15][19]

Gemini 3 家族最新旗舰迭代，gemini-3-pro-preview 端点已指向 3.1。榜单排名领先（详见 DeepMind 模型卡）。上下文预计 ≥100 万，官方未逐一明确。参数未公开。

2026-02~03

Gemini 3.1 Flash Image (Nano Banana 2) / 3.1 Flash-Lite[15]

图像生成档（Nano Banana 2）与低延迟轻量档。上下文 / 参数官方未公开。

2026-07

Gemini 3.6 Flash / 3.5 Flash-Lite / 3.5 Flash Cyber (GA)[20][21]

MoE Flash 系列：3.6 Flash 为主力"工作马"（token 效率↑、编码/智能体规划↑，token 用量最多降约 17%）；3.5 Flash-Lite 最省成本；3.5 Flash Cyber 面向网安（仅政府/可信伙伴）。参数未公开。

命名混乱 & 未决
截至 2026-07，Gemini 3.5 Pro 尚未正式发布（Bloomberg 报道因未达性能基准而延迟）；实际节奏为 3 Pro(2025-11) → 3.1 Pro(2026-02) → 3.6 Flash / 3.5 Flash-Lite(2026-07)，出现 "3.1 Pro 与 3.6 Flash 并存"（Pro 线与 Flash 线号段不同步）。Gemini 4 已确认启动预训练（"迄今最雄心的预训练"），但无规格、无发布时间表。[20][21]

核心技术标签

原生多模态 稀疏 MoE 百万级长上下文 Agentic 工具调用 多模态输出 Deep Think 并行思考 Pathways 分布式训练 TPU v4/v5

① 原生多模态（Gemini 1.0，2023-12 引入）

在 Gemini 之前，多模态多为"文本模型 + 视觉编码器"的后期拼接。Gemini 1.0 从预训练第一步就在文本、代码、图像、音频、视频上联合训练，实现跨模态信息的真正融合，在 20 项多模态基准上全面刷新 SOTA。[6]

② MoE 稀疏专家（Gemini 1.5，2024-02 引入）

1.5 Pro 改为稀疏 Mixture-of-Experts：每次推理只激活一部分专家，做到"总参数可增大而激活参数（单次算力）近似恒定"。此后 2.0 / 2.5 / 3.x 均沿用 MoE 骨干。[8]

③ 超长上下文（Gemini 1.5，2024-02 引入并成为标志）

1.5 Pro 把上下文从 1.0 的 32K 一举推到标准 128K、面向部分用户 100 万，研究中验证到 1000 万 token，且在百万级 token 上保持近乎完美检索（1M 时 99.7% recall）。此后 100 万 token 成为家族默认能力，2.5 规划扩到 200 万。[8][9]

④ Agentic / 原生工具调用与多模态输出（Gemini 2.0，2024-12 引入）

2.0 定位"智能体时代"：可原生调用 Google 搜索、代码执行、地图、第三方函数，并能在一次 API 调用中生成文本+图像+音频的混合输出。[10]

⑤ thinking / Deep Think 显式推理（Gemini 2.5，2025-06 引入）

2.5 系列内置 "thinking"，旗舰 2.5 Pro Deep Think 采用"并行思考"：同时生成并互相批判多个假设再给出答案（研究版达 2025 IMO 金牌水平）。3.x 延续 Deep Think 并进一步强化"推理优先"设计。[12][14]

数据 / 规模

一句话总结
架构从稠密（PaLM / PaLM2 / Gemini 1.0）转向稀疏 MoE（1.5 起）；上下文 2K(PaLM) → 32K(Gemini 1.0) → 128K / 1M(1.5) → 1M 常态(2.0/2.5/3)。参数量则从 PaLM 时代的完全透明，转为 Gemini 时代的整体封闭。
  • PaLM (2022)：官方明确 540B 参数、780B tokens、6144 块 TPU v4。本谱系中唯一官方公开完整参数量 + 训练 token 的旗舰模型。[1][2]
  • PaLM 2 (2023)：Google 官方刻意不再披露参数量与训练量，只强调"计算最优缩放"。CNBC 援引内部文件报道 PaLM 2-L 约 340B 参数、约 3.6T tokens——此为媒体报道，未经 Google 官方确认。[3][4]
  • Gemini 全系（1.0 起）：对旗舰档（Ultra / Pro / Flash）的参数量、训练 token、训练算力一律不公开。唯一公开的具体参数是 Gemini 1.0 Nano-1 = 1.8B、Nano-2 = 3.25B（端侧、蒸馏 + 4bit 量化）。[6]

趋势读法
最能体现"推理优先"跨代跃升的是 ARC-AGI-2（~4.9% → 31.1%） 与 MathArena Apex（0.5% → 23.4%）——从 2.5 到 3 的量级跳变，远大于传统知识类基准（MMLU 早在 1.0 就已接近饱和）。这说明近两代的进步主线已从"知识覆盖"转向"复杂推理 / 智能体执行"。
