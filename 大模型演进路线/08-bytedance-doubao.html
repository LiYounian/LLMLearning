字节 豆包 (Seed) 产品化·极少公开

字节跳动的大模型走了一条与众不同的路：极度产品化、以价格战和调用量叙事切入市场，而纯技术细节（参数量、训练 token、数据构成）几乎从不公开。本文如实标注留白，这也是本系列 8 家里技术透明度最低的一家。

阅读前必读：命名两条线

豆包（Doubao）是面向 C 端 App / B 端火山引擎 API 的产品名；Seed（ByteDance Seed，seed.bytedance.com）是大模型团队的技术/研究名。2025 年起两者合流，火山引擎上的模型 ID 统一为 Doubao-Seed-x.x-*。凡本文出现的第三方推测数字均已注明「存疑」。数据统计截至 2026-08。

发展时间线

主线一句话

豆包(2024) → Doubao 1.5 Pro（稀疏 MoE + 训推一体、高性价比）→ Doubao-1.5-thinking-pro / Seed1.5-Thinking（RL 深度推理）→ Doubao 1.6（256K + AdaCoT + 原生全模态）→ Doubao-Seed-2.0（Agent 化）→ Doubao-Seed-2.1-Pro（生产级 Agent）。独立研究线：UI-TARS（GUI Agent）、Seedream/Seedance（生成矩阵）。

2024-05-15

豆包大模型首发（通用 Pro/Lite + 垂类）

火山引擎「Force 原动力大会」发布，含通用 Pro/Lite 及多个垂直领域模型。以 Pro-32k 输入 0.0008 元/千 tokens、号称比行业低 99.3% 打响国产大模型价格战。前身为抖音/字节内部「云雀」模型的品牌化。发布日日均处理 1200 亿 tokens、生成 3000 万张图。无公开 benchmark，以价格/规模为卖点。

2025-01-22

豆包大模型 1.5（doubao-1.5-pro / -lite / -vision-pro）

确立技术底座：大规模稀疏 MoE + 训练-推理一体化设计。官方称用更小激活参数达到「7 倍激活参数 Dense 模型」的性能（MoE 效率杠杆约 7×，高于行业约 3×）。强调数据自建、不蒸馏其他模型。官方自评综合分超 GPT-4o、Claude 3.5 Sonnet（未给逐项分）。参数量官方未公开。

2025-04（约 4/17）

Doubao-1.5-thinking-pro = Seed1.5-Thinking（深度思考）

引入大规模 RL 训练的深度思考能力。MoE 总 200B / 激活 20B——这是主线里罕见的官方公开数字（技术报告 arXiv 2504.13914）。训练框架 HybridFlow + Ray，20ms 级低延迟。AIME 2024 86.7、Codeforces 55.0、GPQA 77.3；总体超 DeepSeek-R1(671B)，非推理任务胜率高约 8%。

2025-05-13

Seed1.5-VL（= doubao-1-5-thinking-vision-pro-250428）

多模态理解模型：视觉编码器 532M + MoE LLM 激活 20B（LLM 总参数未公开）。60 个公开多模态基准中 38 项 SOTA；GUI/游戏智能体任务优于 OpenAI CUA、Claude 3.7。技术报告 arXiv 2505.07062，代码开源。

2025-06-11

豆包大模型 1.6（Doubao-Seed-1.6 / -thinking / -flash）

稀疏 MoE、原生全模态。256K 上下文（官方称国内首个达此规模的旗舰）。引入 AdaCoT 自适应思维链：模型自行判断该不该展开长推理，兼顾质量与成本；视觉-语言原生统一进主模型。较 1.5 降价约 63%，最低 2.60 元/百万 tokens。第三方(oreateai)称约 230B 总 / 23B 激活——未获官方确认，存疑。

2026-02-14

Doubao-Seed-2.0 系列（Pro / Lite / Mini + Code）

定位从「聊天助手」转向「通用 Agent 模型」：深度推理、长链任务、面向大规模生产。Pro 256K 上下文。官方称在 IMO / CMO / ICPC 等竞赛级任务有能力展示（官方口径，未给可复核成绩）。参数量官方未公开。

2026-05-06

Doubao-Seed-2.0-lite 升级（家族首款全模态理解）+ 新增 -mini

视频/图像/音频/文本原生统一理解；音频 19 语种转写、中英+14 语种互译；Agent 多轮反思 + 多智能体协同；Coding 支持前端/3D/游戏；GUI 操作。官方称在 HiPhO、MedXpertQA、细粒度感知、具身理解等超 Gemini-3.1-Pro（官方口径，未给具体分）。

2026-06-23

Doubao-Seed-2.1-Pro（夏季 FORCE 大会）

主打「生产级 Agent」：代码交付、长程 Agent 任务、多模态理解、企业级稳定运行四维「生产级突破」。官方称整体性能对标 GPT-5.5、Claude Opus 4.7、Gemini 3.1 Pro（纯官方自评，无第三方复核）。同期补齐 Seedream 5.0 Pro / Seedance 2.5 / Seed-Audio 1.0。

核心技术标签

大规模稀疏 MoE 训练-推理一体化 性价比 ~7× 激活效率杠杆 价格战 / 高并发 RL 深度推理（Seed1.5-Thinking） AdaCoT 自适应思维链 原生视觉-语言 → 全模态统一 UI-TARS GUI Agent Seedream/Seedance 生成矩阵 不蒸馏、数据自建

五条技术主线

A · MoE + 高性价比（贯穿全程的产品逻辑）：2024 首发即以「降价 99.3%」切入，把「低价 + 高并发」而非刷榜作为核心竞争力。Doubao 1.5 Pro 确立大规模稀疏 MoE + 训推一体底座（约 7× 激活效率杠杆）；1.6 再降价 63% 把 token 价压到 2.6 元/百万。价格战是字节大模型贯穿始终的主线。

B · 深度思考 / RL 推理（2025-04 引入）：Doubao-1.5-thinking-pro（= Seed1.5-Thinking）用 MoE 总 200B / 激活 20B、远小于 DeepSeek-R1(671B) 的规模取得可比甚至更优的推理成绩。到 1.6 演进为 AdaCoT，模型自行决定是否展开长推理。

C · 多模态 → 全模态统一理解：Seed1.5-VL（532M 视觉 + 20B 激活）打通视觉-语言（60 基准 38 SOTA）→ Doubao 1.6 首次原生统一进主模型 → Doubao-Seed-2.0-lite 成为家族首款「全模态理解」（视频/图像/音频/文本，音频 19 语种）。

D · GUI Agent 与 Agent 化：UI-TARS 独立线（2025-01 原论文 → 1.5 开源 → 2.0 游戏达约 60% 人类水平）是字节 computer-use 方向的旗舰研究。主模型自 Doubao-Seed-2.0 起转向「通用 Agent」，2.1-Pro 主打「生产级 Agent」，2026 主线明确转向 Coding 与 Agent。

E · 生成模型矩阵：与 LLM 平行演进——Seedream 图（3.0→4.0→5.0 Pro）、Seedance 视频（1.0→2.5）、2026-06 补齐 Seed-Audio 1.0，形成「文/图/视频/音频」全生成矩阵。

数据 / 规模

这是全系列透明度最低的一家

主 LLM 线（豆包首发 / 1.5-pro / 1.6 / 2.0 / 2.1-Pro）的总参数、激活参数、训练 token 量、训练数据构成官方一律未公开。字节对新旗舰「重发布、轻技术报告」的风格加剧了这一空白。凡本文出现的数字，要么来自技术报告（可信），要么已注明第三方存疑。

  • 参数量：唯一有官方数字的是推理模型 Doubao-1.5-thinking-pro / Seed1.5-Thinking = 总 200B / 激活 20B。Seed1.5-VL 公开了视觉编码器 532M + LLM 激活 20B，但 LLM 总参数未公开。Doubao 1.6 的「230B 总 / 23B 激活」仅见于第三方(oreateai)，未获官方确认，本文不采信为事实。
  • 训练 token 量 / 数据构成：全系官方未公开。Doubao 1.5 官方仅定性强调「不走捷径、不蒸馏其他模型、数据自建」；Seed1.5-VL 技术报告称预训练用「数万亿多模态 token」。
  • 上下文长度：仅 Doubao 1.6 官方明确 256K（称国内首个达此规模的旗舰）；2.0-Pro「256K」来自第三方转述；早期仅知有「Pro-32k」版本。
  • 可对外量化的只有「使用量 / 价格」：2024-05 发布日日均处理 1200 亿 tokens、生成 3000 万张图；月活曾达约 2600 万；到 2026 FORCE 大会官方称日均 token 调用突破 180 万亿。字节的「规模叙事」始终落在调用量与价格，而非模型参数。
