DeepSeek 开放权重

杭州幻方量化旗下深度求索（2023 成立）。以「开源权重 + 技术报告透明公开训练细节 + 极致工程降本」三板斧著称：MLA 把 KV cache 压 93.3%、DeepSeekMoE 降推理成本、GRPO 首创、FP8 训练把 V3 正式预训练成本压到约 550 万美元、纯 RL 推理登上 Nature、DSA 稀疏注意力把长文注意力复杂度从 O(L²) 降到 O(L·k)。

一句话定位
在开源阵营里透明度最高：不仅放权重，还在技术报告里公布训练 token 量（2T→8.1T→14.8T）与 GPU 时（V3 = 2.788M H800 GPU 时）。用架构创新（MLA / DeepSeekMoE）+ 工程创新（FP8 / MTP / DSA）+ 算法创新（GRPO / 纯 RL）三条腿走出一条低成本高性能路线。

发展时间线

2024-01（论文）

DeepSeek LLM 7B / 67B — 奠基

稠密 Transformer，4K 上下文，2T tokens 自建语料。以 scaling law 实证 + SFT+DPO 对齐，确立「scaling law 指导 + 开源」路线；67B 在 MATH / GSM8K / HumanEval / BBH 及中文基准全面超 LLaMA2-70B。[1]

2024-01（论文）

DeepSeek-Coder 1.3B–33B — 代码

稠密，16K 上下文，2T tokens（87% 代码 + 13% 自然语言）。项目级代码语料 + FIM 填空目标，开源代码模型 SOTA，超 Codex、GPT-3.5。[2]

2024-02（论文）

DeepSeekMath 7B — 首创 GRPO

在 Coder-v1.5 基础上 +120B 数学 token 持续预训练。首次提出 GRPO（组相对策略优化）；MATH 51.7%（无外部工具、无投票），逼近 GPT-4 / Gemini-Ultra。[3]

2024-05

DeepSeek-V2 — MLA + DeepSeekMoE

MoE 236B / 21B，128K 上下文，8.1T tokens。引入 MLA（多头潜在注意力）+ DeepSeekMoE：相比 67B 省 42.5% 训练成本、KV cache 降 93.3%、吞吐提升 5.76×。[4]

2024-06

DeepSeek-Coder-V2 — MoE 用于代码

MoE 16B/2.4B 与 236B/21B 两档，128K。从 V2 中间检查点 +6T tokens，语言覆盖 86→338 种；代码 / 数学基准超 GPT4-Turbo、Claude 3 Opus、Gemini 1.5 Pro。[5]

2024-12

DeepSeek-V3 — 671B / FP8 / MTP，约 550 万美元

MoE 671B / 37B，128K，14.8T tokens。FP8 混合精度训练 + MTP 多 token 预测 + 无辅助损失负载均衡；训练仅 2.788M H800 GPU 时（约 550 万美元），MMLU 88.5，对标 GPT-4o / Claude-3.5-Sonnet，震动业界。[6]

2025-01

DeepSeek-R1 / R1-Zero — 纯 RL 推理登 Nature

基于 V3-Base 的 MoE 671B / 37B，128K。纯 RL（GRPO）激发推理；R1-Zero 无 SFT 冷启动、直接 RL，自发涌现自我验证、反思、「aha moment」。AIME 2024 79.8%、MATH-500 97.3%、Codeforces 2029 Elo（对标 o1-1217）。该工作发表于 Nature。[7][8]

2025-03 / 2025-05

V3-0324 / R1-0528 — 增量升级

架构同前，后训练增强。V3-0324：MMLU-Pro 75.9→81.2、AIME 39.6→59.4、LiveCodeBench 39.2→49.2；R1-0528（思考 token 近翻倍）：AIME 2025 70.0→87.5、GPQA 71.5→81.0、Aider 57.0→71.6。（增量训练量官方未公开）[11][12]

2025-08

DeepSeek-V3.1 — 混合推理

MoE 671B / 37B。混合推理（thinking / non-thinking 可切换），统一对话与推理；适配国产加速器。增量数据量官方未公开。[12]

2025-09

DeepSeek-V3.2-Exp — DSA 首发（实验版）

在 V3.1-Terminus 上继续训练，首发 DeepSeek Sparse Attention（DSA）。性能与 V3.1-Terminus 持平，API 降价 50%+，同步开源权重与 TileLang / CUDA 内核。[9]

2025-12

DeepSeek-V3.2（正式）/ -Speciale — DSA 正式化

DSA 正式化：注意力复杂度 O(L²)→O(L·k)。标准版对标 GPT-5；-Speciale 版在 2025 IMO 与 IOI 均获金牌级成绩。配套 arXiv 论文 2512.02556。[10]

2026-04

DeepSeek-V4-Pro / V4-Flash — 1M 上下文

Pro 1.6T / 49B、Flash 284B / 13B，1M 上下文默认。Token-wise 压缩 + DSA 混合注意力。Pro 世界知识对标 Gemini-3.1-Pro、agentic 编码强化；Flash 逼近 Pro。训练 token / 成本 / 具体基准分数官方公告未列。[13]

R2 至今未发布
截至 2026-08，DeepSeek-R2 不存在，官方多次辟谣 3 月、8 月发布传闻。网传「R2 为 32B 稠密、AIME 2025 92.7%」等规格均为泄露 / 猜测，不可信；「CEO 因性能不满意暂缓、Ascend 训练受阻转回 Nvidia」属媒体报道 / 传闻，非官方确认。

核心技术标签

MLA 多头潜在注意力 DeepSeekMoE GRPO 首创 FP8 混合精度训练 MTP 多 token 预测 纯 RL 推理 DSA 稀疏注意力 无辅助损失负载均衡

技术演进主线

  • MLA（Multi-head Latent Attention） — V2（2024-05）引入。把 KV cache 压缩成低维潜在向量，推理时 KV cache 降 93.3%，是长文本 + 低推理成本的核心，此后 V2/V3/R1/V3.x/V4 全线沿用。[4]
  • DeepSeekMoE — V2（2024-05）引入。细粒度专家切分 + 共享专家隔离；V3 进一步用无辅助损失（auxiliary-loss-free）负载均衡替代传统辅助损失，避免负载均衡损失损害性能。[4][6]
  • GRPO（Group Relative Policy Optimization） — DeepSeekMath（2024-02）首创。PPO 变体，用组内多采样的相对优势估计替代 critic 网络，省显存又稳，后成为 R1 纯 RL 推理的核心算法。[3]
  • FP8 混合精度训练 — V3（2024-12）大规模落地。E4M3 格式 + tile/block-wise 分块量化抑制离群值，是 V3 训练成本仅约 550 万美元的关键工程手段之一。[6]
  • MTP（Multi-Token Prediction） — V3（2024-12）引入。训练时增设多 token 预测目标，提升数据效率与性能，并可用于推理加速。[6]
  • 纯 RL 推理（R1-Zero） — R1（2025-01）。R1-Zero 在 V3-Base 上不经 SFT 冷启动、直接 RL，自发涌现推理行为；R1 加少量冷启动 CoT 数据改善可读性。发表于 Nature。[7][8]
  • 混合推理（Hybrid thinking） — V3.1（2025-08）。同一模型可在思考 / 非思考模式间切换，统一对话与推理。[12]
  • DSA（DeepSeek Sparse Attention） — V3.2-Exp（2025-09）首发、V3.2 正式化、V4 沿用。细粒度稀疏注意力把注意力复杂度从 O(L²) 降到 O(L·k)，长文本大幅提速降内存而基本不损质量，是 V4 默认 1M 上下文的基础。[9][10]

数据 / 规模

DeepSeek 是开源阵营里预训练规模披露最透明的团队：预训练 token 量沿 2T → 8.1T → 14.8T 递进，V3 更罕见地公布了 GPU 时（2.788M H800 GPU 时）。
