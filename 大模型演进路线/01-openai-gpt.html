OpenAI GPT 闭源为主

从「预训练 decoder-only Transformer + 规模定律」起家，经 RLHF 对齐走向对话，经多模态（GPT-4o）与推理模型（o 系列）两次范式跃迁；GPT-5 起把「快速模型 + 深度推理模型 + 实时路由」合成一个统一系统。

发展时间线

下表仅列重要版本；数字凡官方未公开处均标注「未公开」。完整表格见页内叙述与来源。

2018-06 · GPT-1

Decoder-only Transformer · 117M（官方公开）· 512 token

确立「生成式预训练 + 判别式微调」的半监督两阶段范式。训练语料 BooksCorpus（约 7000 本书 / 约 5GB / ~8 亿词，token 量级约 10 亿，官方未精确给 token 数）。在多项 NLU 任务上刷新 SOTA。[1]

2019-02 公告 / 2019-11 全量放出 · GPT-2

Decoder-only Transformer · 1.5B 最大档（官方公开）· 1024 token

纯无监督、zero-shot 多任务；首创「分阶段发布」的安全策略（先小档、后 1.5B 全量）。语料 WebText 约 40GB / 800 万网页（Reddit ≥3 karma 外链），约 100 亿 token（外界估算）。另有 117M/345M/762M 档。[2][3]

2020-05 · GPT-3

Decoder-only Transformer · 175B（官方公开，96 层）· 2048 token

规模定律（scaling law）大规模验证；提出 in-context learning / few-shot——在 prompt 里给几个示例即可完成新任务，无需梯度更新。约 3000 亿 token（Common Crawl 过滤 + WebText2 + Books1&2 + Wikipedia 混合加权）。MMLU few-shot ~43.9%。[4][5]

2022-01 · InstructGPT

GPT-3 + RLHF 对齐 · 基于 175B 及更小档

RLHF：SFT（标注者书写示范）+ 奖励模型 + PPO 强化学习，实现指令跟随对齐。人评偏好度约 85% 场景优于同规模 GPT-3，毒性 / 编造下降；对齐后 1.3B 版本人评已胜过 175B GPT-3。后训练数据具体样本量官方未精确公开。[6]

2022-11-30 · ChatGPT（GPT-3.5）

GPT-3.5 + 对话式 RLHF · 参数量未公开 · 约 4k（后 16k 变体）

对话式 RLHF + 产品化聊天界面，把语言模型变成可对话助手。5 天破 100 万用户（产品指标）。[6][7]

2023-03-14 · GPT-4

多模态（图文输入）Transformer · 规模官方未公开 · 8k / 32k 变体

首次在旗舰引入图像输入，复杂推理与专业考试能力大幅提升，并发布 System Card。官方明确拒绝披露规模 / 架构 / 数据 / 硬件。MMLU ~86.4%；多项人类专业考试达 top 10% 级别（如模拟律考）。[8][9]

2024-05-13 · GPT-4o（"omni"）

原生多模态单一模型（文/图/音）· 规模未公开 · 128k

文本 / 图像 / 音频在单一模型内原生统一，支持端到端语音-语音，延迟与成本大幅下降。知识截止 2023-10。MMLU 88.7%；语音 / 多语言 / 视觉多项 SOTA。[10]

2024-09-12 预览 / 2024-12-05 正式 · o1

推理模型（RL + 私有思维链）· 规模未公开

推理模型范式：模型在回答前用私有 CoT「思考」，思考越久越准（test-time compute）。数学 / 竞赛编程 / 科学（AIME、Codeforces 等）大幅超越 GPT-4o。[11][12]

2025-01 → 2025-06 · o3 系列

推理模型（放大 RL）· 规模未公开

o3-mini（2025-01-31）/ o3（2025-04-16）/ o3-pro（2025-06-10）。放大强化学习 + 推理时搜索；引入 deliberative alignment 安全对齐。编程 / 数学 / 科学再刷 SOTA，ARC-AGI 大幅提升（部分为传闻 / 报道口径）。[13]

2025-02-27 · GPT-4.5（代号 Orion）

大规模非推理模型 · 规模未公开 · 128k

迄今最大的非推理预训练模型；定位「更自然 / 更少幻觉」，不走显式 CoT。非推理基准提升。[14]

2025-04-14 · GPT-4.1（API 系列）

GPT-4o 演进（含 mini / nano）· 规模未公开 · 1,000,000 token

超长上下文（100 万 token）；强化编程、指令跟随、长文理解，仅 API 提供。知识截止 2024-06。SWE-bench 编程与长上下文基准显著优于 GPT-4o。[15]

2025-08-07 · GPT-5

统一系统 + 实时路由（main / thinking 多档 + router）· 规模未公开

路由器按问题复杂度自动在「快速模型」与「深度推理模型」间切换，对用户屏蔽选型；原生多模态。上下文产品端 128k~、API 更大（官方披露不一致）。AIME 2025 无工具 94.6%；SWE-bench Verified 74.9%；MMMU 84.2%；HealthBench Hard 46.2%。[16][17][22]

2025-11 → 2026-07 · GPT-5.1 / 5.2 / 5.4 / 5.5 / 5.6

统一系统持续迭代（instant / thinking / pro / Codex 变体）· 规模未公开

快速小步迭代：编程 Codex 专用档、知识工作与 agent（ChatGPT Work）、token 效率优化。GPT-5.6 Sol：Artificial Analysis Coding Agent Index v1.1 得分 80（最大推理档），官方称「最强编程 / 网络安全模型」且更省 token。[18][19][20][21]

GPT-5.x 关键日期
GPT-5.1（2025-11-12，另有两款 11-19 补发）· GPT-5.2（2025-12-11，含 instant/thinking/Pro + GPT-5.2-Codex）· GPT-5.3-Codex（2026-02-05）· GPT-5.4（2026-03-05）· GPT-5.5（2026-04-23）· GPT-5.6（2026-06-26 预览 / 2026-07-09 公开，Sol/Terra/Luna 三档 + ChatGPT Work agent）。[18][19][20][21]

核心技术标签

生成式预训练 无监督 zero-shot 规模定律 scaling law in-context learning / few-shot RLHF 对齐 对话式 RLHF 图像多模态 原生 omni 多模态 推理模型 / test-time compute deliberative alignment 超长上下文 1M 统一系统 + 实时路由 Agent 化 / token 效率

  • Decoder-only Transformer + 生成式预训练（GPT-1，2018）：确立「先在大规模无标注语料上自回归预训练，再在下游微调」的两阶段范式，奠定整个 GPT 家族的架构底座。[1]
  • 无监督多任务 / zero-shot（GPT-2，2019）：证明模型和数据足够大时，单一语言模型无需任务专用微调即可 zero-shot 完成多任务；同时首创「分阶段发布」安全策略。[2][3]
  • 规模定律 + in-context learning（GPT-3，2020）：把参数量放大到 175B 验证 scaling law；提出「在 prompt 里给几个示例即可完成新任务」，无需梯度更新。[4]
  • RLHF 对齐（InstructGPT / ChatGPT，2022）：用「监督微调 + 奖励模型 + PPO 强化学习」让模型跟随人类指令、更有用更少有害——把原始语言模型变成可对话助手的关键一步。[6]
  • 图像多模态（GPT-4，2023）：首次在旗舰引入图像输入，复杂推理与专业考试能力大幅提升；同时开始对规模 / 架构 / 数据完全保密。[8][9]
  • 原生 omni 多模态（GPT-4o，2024）：文本 / 图像 / 音频在单一模型内原生统一，支持端到端语音-语音，延迟与成本大幅下降。[10]
  • 推理模型 / test-time compute（o1 → o3，2024–2025）：用 RL 训练模型在回答前生成私有思维链「思考」，把算力从训练时转向推理时（think longer → 更准）；o3 进一步放大 RL 并引入 deliberative alignment。[11][13]
  • 超长上下文（GPT-4.1，2025）：上下文扩到 100 万 token，并提升长文理解与利用能力。[15]
  • 统一系统 + 实时路由（GPT-5，2025）：把「快速模型 + 深度推理模型」合成一个系统，用 router 按复杂度 / 工具需求 / 用户意图自动选择，对用户屏蔽选型。[16][17]
  • Agent 化与 token 效率（GPT-5.x → 5.6，2026）：面向 agentic 工作流（ChatGPT Work）、编程（Codex 专用档）持续迭代，强调「用更少 token 达到更高智能」。[19][20][21]

数据 / 规模

  • 预训练 token 量（可核实部分）：GPT-1 语料 BooksCorpus（约 5GB / ~8 亿词，token 量级约 10 亿，官方未精确给数）→ GPT-2 WebText 约 40GB / 800 万网页（外界估约 100 亿 token）→ GPT-3 约 3000 亿 token（官方论文给出）。[1][2][4]
  • 参数量（官方公开部分）：117M（GPT-1）→ 1.5B（GPT-2 最大档）→ 175B（GPT-3）。GPT-4 起官方不再公开。[1][3][4][9]
  • 数据配比变化：GPT-3 首次公开混合加权配方——Common Crawl（质量过滤）+ WebText2 + Books1&2 + Wikipedia，高质量语料上采样。此后（GPT-4 及以后）数据来源与配比官方未公开，仅笼统表述为「书籍 / 文章 / 网页 / 学术论文 / 授权数据」等多语种大规模语料。[4][16]
  • 后训练数据规模：InstructGPT 公开了后训练由「标注者示范（SFT）+ 人工偏好比较（奖励模型）」两部分组成，但具体样本量官方未精确公开；ChatGPT 及以后的后训练（含 RLHF、推理 RL）数据规模均未公开。[6]
传闻 / 存疑，切勿当事实
GPT-4 的「约 1.8T、MoE、8×220B」等说法均为媒体 / 研究者传闻（如 Semafor 报道「1 万亿参数量级」），OpenAI 从未证实。Sam Altman 仅确认训练成本超 1 亿美元。GPT-4 及以后的参数量 / 架构 / 训练数据全部官方未公开。

总体趋势：2020 年前是「公开参数 / 数据、拼规模」；2023 年 GPT-4 起转为「全面保密规模与数据」，公开叙事重心从「多大」转向「多能」（推理、多模态、agent、token 效率）。

口径提醒
o1 / o3 阶段官方主要以 AIME、Codeforces、GPQA、ARC-AGI 等展示，分数随档位与是否用工具 / 是否 majority vote 差异很大，不同来源数字不可直接横比，此处不逐一列举以免混淆口径。GPT-5.x 的上下文窗口官方文档披露不一致（产品端与 API 端不同），本页标「未公开 / 因档位而异」。

不确定与空白

  • GPT-4 及以后的参数量 / 架构 / 训练数据全部官方未公开；「1.8T / MoE」为未证实传闻。
  • 上下文长度：GPT-4（8k/32k）、GPT-4o（128k）、GPT-4.1（1M）为官方明确数字；GPT-5 及 GPT-5.x 官方披露不一致，标「未公开 / 因档位而异」。
  • 训练 token 量：仅 GPT-3（3000 亿）由官方论文给出确切数字；GPT-1 约 10 亿、GPT-2 约 100 亿为外界估算；GPT-3.5 及以后均未公开。
  • 后训练（RLHF / 推理 RL）数据规模：InstructGPT 公开方法与流程，但样本量级、ChatGPT 及后续对齐数据规模均未公开。
  • GPT-5.x 高频小版本（5.1/5.3-Codex/5.4/5.5/5.6）迭代极快，多数只有发布说明与第三方评测，缺乏 system card 级技术细节；部分中间版本资料稀疏。
