Meta Llama 开放权重

当今影响力最大的开放权重大模型家族：从 LLaMA 1 奠定 decoder-only Transformer 的「标准配方」（RMSNorm + RoPE + SwiGLU），到 Llama 4 首次转向 MoE 与原生多模态，Llama 系列既是技术风向标，也孕育了 llama.cpp / Ollama / Alpaca / Vicuna 等庞大生态。

Meta（AI at Meta，前身 FAIR）的 Llama（Large Language Model Meta AI）自 2023.02 初代起就以放出权重为核心策略：LLaMA 1 采用研究许可，Llama 2 起转为商用友好许可。它奠定了当代主流架构范式——Pre-normalization + RMSNorm、RoPE 旋转位置编码、SwiGLU 激活，后续加入 GQA 分组查询注意力，被业界广泛沿用。

发展时间线

2023.02 · Dense

LLaMA 1 — 7B / 13B / 33B / 65B

纯研究许可。定型「标准配方」：Pre-norm + RMSNorm、RoPE、SwiGLU，仅用公开数据训练。小模型 1.0T、33B/65B 1.4T tokens；上下文 2048。论文称 LLaMA-13B 多数基准超 GPT-3(175B)，65B 与 Chinchilla-70B / PaLM-540B 竞争。[1]

2023.07 · Dense

Llama 2 — 7B / 13B / (34B*) / 70B

转商用友好许可，生态爆发。34B/70B 首次引入 GQA；上下文扩到 4096；2.0T tokens 预训练。Chat 版首次系统化 RLHF：SFT → 奖励模型 → 拒绝采样 + PPO，并单独训练安全奖励模型。34B 因安全对齐未达标未公开放出权重。[2]

2024.04 · Dense

Llama 3 — 8B / 70B

换用 128K 词表 tokenizer，全尺寸（含 8B）都用 GQA；更强数据清洗，>15T tokens；上下文 8192。同尺寸大幅超 Llama 2，达开源 SOTA 级。[6]

2024.07 · Dense

Llama 3.1 — 8B / 70B / 405B

首个 405B dense 旗舰；上下文扩到 128K；强化多语言与工具调用。405B 训练于约 15.6T 文本 token。后训练转向 SFT + 拒绝采样 + DPO 路线。官方与论文称在众多任务上「比肩 GPT-4」，为当时最强开放权重模型。[3]

2024.09 · Dense（视觉+文本）

Llama 3.2 — 视觉 11B/90B + 端侧 1B/3B

首次多模态视觉：11B/90B 通过视觉编码器 + 交叉注意力接入图像理解。1B/3B 面向手机/边缘，day-one 支持 Arm、高通、联发科，128K 上下文。基于 3.1 蒸馏/继续训练（官方未给独立 token 总量）。11B/90B 图像理解超 Claude 3 Haiku 等。[8]

2024.12 · Dense

Llama 3.3 — 70B（仅一款）

纯靠后训练强化，让 70B 追平 3.1 405B 性能、成本大降，体现「后训练红利」。上下文 128K；继承 Llama 3 数据（官方未单列）。IFEval 达 92.1（官方称超 405B），MATH、MGSM 相对 3.1 70B 显著提升。[7]

2025.04 · MoE（原生多模态）

Llama 4 Scout — 17B active / 109B total / 16 experts

首次 MoE + 原生多模态（early fusion 混合文本+图像+视频 token）；采用 iRoPE（交错局部/全局注意力、部分层无显式位置编码）。宣称 10M tokens 上下文（存疑，见下）；预训练约 40T tokens。Int4 量化下可单卡 H100 部署。官方称同类最佳多模态，超 Gemma 3 / Gemini 2.0 Flash-Lite / Mistral 3.1。[4]

2025.04 · MoE（原生多模态）

Llama 4 Maverick — 17B active / 400B total / 128 experts

同代 MoE 多模态，面向通用助手，交替 dense/MoE 层；宣称 1M tokens；预训练约 22T tokens。官方称超 GPT-4o、Gemini 2.0 Flash，接近 DeepSeek v3；但 LMArena 上榜为「对话优化实验版」而非公开权重版，存在榜单争议。[4]

2025 · MoE（预览，未发布）

Llama 4 Behemoth — 288B active / ~2T total / 16 experts

定位教师模型（用于蒸馏 Scout/Maverick），仍在训练。官方 2025.04 预览称 STEM 基准超 GPT-4.5 / Claude Sonnet 3.7 / Gemini 2.0 Pro。此后多次推迟，媒体报道称因 2T 规模下 MoE 训练问题，Meta 至今未公开发布，也未正式宣布取消。[5]

核心技术标签

开放权重 RMSNorm RoPE SwiGLU GQA 分组查询注意力 RLHF（拒绝采样+PPO） DPO iRoPE MoE 混合专家 原生多模态 early fusion 端侧 / 小模型 128K→10M* 长上下文

标准配方（LLaMA 1 定型）

  • Pre-normalization + RMSNorm：归一化放在子层输入端，用 RMSNorm 替代 LayerNorm，训练更稳。
  • RoPE 旋转位置编码：相对位置注入，利于长度外推，成为后续所有版本基础。[1]
  • SwiGLU 激活：门控前馈替代 ReLU/GeLU，提升表达力。
  • 以上三件套自 LLaMA 1 起贯穿全系列，被业界广泛沿用。

GQA 分组查询注意力

Llama 2 的 34B/70B 首次引入，用「多于 1、少于 query 头数」的 KV 头数，在多头注意力质量与多查询注意力速度间取平衡，减少 KV cache 显存、加速长序列推理。Llama 3 起全尺寸（含 8B）都用 GQA。[9]

对齐 / 后训练演进

  • Llama 2-Chat 首次系统化 RLHF：SFT → 奖励模型 → 拒绝采样 + PPO 迭代，并单独训练安全奖励模型。
  • Llama 3/3.1 转向更工程化的 SFT + 拒绝采样 + DPO，强化多语言、代码、推理、工具调用。[10]
  • Llama 3.3 主要靠后训练把 70B 拉到接近 3.1 405B 的水平，体现「后训练红利」。

架构范式切换（Dense → MoE）与多模态

  • MoE：Llama 4 首次采用，每 token 只激活部分专家（Scout 17B active/109B total；Maverick 17B active/400B total），从 dense 转向 sparse。
  • 原生多模态：Llama 3.2 首次加视觉（视觉编码器 + 交叉注意力）；Llama 4 升级为 early fusion，预训练即混合文本+图像+视频 token。
  • iRoPE：Llama 4 用交错局部/全局注意力、部分层无显式位置编码，支撑超长上下文。
  • 长上下文演进：2048（LLaMA 1）→ 4096（Llama 2）→ 8192（Llama 3）→ 128K（3.1/3.2/3.3）→ Scout 宣称 10M。

数据 / 规模

Llama 系列的显著特征是训练 token 量远超 Chinchilla 最优（「过度训练」以换取推理期高效的小模型）。规模级差：LLaMA 1 的 1.0–1.4T → Llama 2 翻倍到 2T → Llama 3 一跃约 8 倍至 15T+ → Llama 4 扩到 30–40T 量级并混入多模态数据。
