2017 · Attention Is All You Need

正弦 / 余弦绝对位置编码 Sinusoidal

原始 Transformer 给出的第一个答案：用一组不同频率的正弦、余弦函数，为每个位置算出一个固定向量，直接加到词向量上。不需要训练，理论上还能外推到没见过的长度。

被这些模型使用： 原始 Transformer (2017) 后被 learned / RoPE 取代

① 核心思想：给每个位置一张"频率指纹"

想象一排不同速度的时钟指针：有的转得快（高频），有的转得慢（低频）。把某个位置在所有这些指针上的读数拼起来，就得到一个独一无二的向量——这就是该位置的编码。位置越靠后，这组读数的组合就越不同。

形式上，对位置 pos、维度下标 i（向量共 d 维），偶数维用 sin、奇数维用 cos：

PE(pos, 2i) = sin( pos / 100002i/d )
PE(pos, 2i+1) = cos( pos / 100002i/d ) 分母 100002i/d 控制"这一维指针转多快"：i 越大，波长越长、频率越低。最低维波长约 2π，最高维波长长达约 10000·2π——覆盖了从极快到极慢的一整段频率。

算好后，位置向量直接加到对应位置的词向量上：输入ᵢ = 词向量ᵢ + PE(i)。仅此一步，顺序信息就进了模型。

② 热力图：亲眼看这套编码长什么样（可交互）

下图每一行是一个位置、每一列是一个维度，颜色是该处的编码值（正暖色、负冷色）。低维（左侧）像细密的条纹（高频），高维（右侧）像宽阔的色带（低频）。拖动滑块调序列长度和维度，点某一行看该位置的完整编码向量。

③ 为什么偏偏用 sin/cos？——相对位置的线性表达

这不是随便挑的三角函数。关键性质：任意偏移 k 的位置编码，都能由当前位置编码经一个固定的线性变换得到。因为对同一频率 ω：

sin(ω(pos+k)) = sin(ω·pos)·cos(ωk) + cos(ω·pos)·sin(ωk) 这正是二维旋转公式。也就是说 PE(pos+k) 是 PE(pos) 的一个只依赖 k（与 pos 无关）的旋转/线性组合。模型因此有机会从绝对编码里学出"相对距离"——这个"旋转"直觉，正是四年后 RoPE 的思想源头。

④ 它解决了什么、又留下什么

✓ 优点

  • 零参数、不用训练：直接算出来，不占 embedding 表。
  • 理论上可外推：任意大的 pos 都能算，不像查表法有长度上限。
  • 蕴含相对结构：sin/cos 让相对位移有线性表达，利于模型泛化。
  • 确定、可复现：同一位置永远同一编码。

✗ 局限

  • "加法注入"较弱：位置和语义在同一向量里相加、互相干扰，不如后来把位置作用在注意力上直接。
  • 外推实测打折：理论能算，但没训练过的长距离，效果常明显下降。
  • 仍是绝对位置：模型得自己"悟"出相对关系，不如显式相对方法。
  • 实践中很快被学习式绝对编码与 RoPE 取代。

⑤ 被哪些模型使用

正弦编码的"生产代表作"就是原始 Transformer（2017）本身。论文里作者也试了可学习版本，效果相近，最终选正弦版因为它能外推。此后 BERT/GPT 转向学习式绝对编码，主流生成式模型再转向 RoPE——但正弦编码里"用旋转承载位置"的种子，一直影响到今天。
