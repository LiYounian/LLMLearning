RoPE：旋转位置编码

今天开源大模型的绝对主流。核心一招：按位置把 Query、Key 向量旋转一个角度。神奇之处在于——两个旋转后向量的内积，会自动只依赖它们的相对位置差。绝对的形式，相对的效果。

被这些模型使用： LLaMA 全系 Qwen 全系 DeepSeek (MLA decoupled RoPE) ChatGLM · Mistral · Gemma · Falcon · GPT-NeoX · PaLM

① 核心思想：把"位置"变成"旋转角"

前面所有方法都是"给向量加点位置信息"。RoPE 换成"给向量转个角度"。具体做法：把 d 维的 Query/Key 每两维分成一组（一个 2D 平面），在位置 m 处，把第 k 组的这对分量旋转 m·θk 弧度：

q̃m = R(m·θ) · q     k̃n = R(n·θ) · k R(·) 是旋转矩阵；位置越靠后转得越多。每组用不同频率 θk = 10000−2k/d——和正弦编码同一套频率阶梯：低维转得快、高维转得慢。

② 神来之笔：内积只剩相对位置

注意力要算的是 Query 和 Key 的内积。把旋转后的 q̃m 和 k̃n 做内积，两个旋转会合并成一个只含 (n−m) 的旋转：

⟨ R(mθ)q , R(nθ)k ⟩ = ⟨ q , R((n−m)θ)k ⟩ 因为旋转矩阵满足 R(a)⊤R(b)=R(b−a)。绝对位置 m、n 单独看都在，但一做内积就抵消成相对位置 n−m。这就是 RoPE 的全部魔法：用绝对旋转，得到纯相对的注意力。
🔑 一句话记住
位置编码在做内积那一刻才"显形"，且只显形为相对距离。既不用像 learned 那样占长度上限，也不用像 Shaw 式相对编码那样在注意力里塞额外的向量——旋转本身就把相对信息编进去了。

③ 旋转可视化（可交互）

下面把一组 Query（蓝）和 Key（绿）画在 2D 平面上。拖 m、n 两个滑块改变它们所在位置：两个向量各自旋转 m·θ、n·θ，但它们的夹角只由 (n−m) 决定——这正是内积所"看见"的量。试着让 m、n 一起增大：夹角不变。

④ 它一举解决了前几代的什么问题

前代痛点RoPE 的回答
learned 绝对编码有长度上限旋转对任意位置都能算，无表可爆
Shaw 式相对编码要往注意力塞向量、复杂且慢只旋转 Q/K，不加任何参数，对 KV cache 友好
绝对编码相对关系要模型硬悟内积天然=相对距离函数，直接给到
正弦编码的旋转直觉没落到注意力上把"旋转"从加法项升级成作用在 Q/K 的真旋转

⑤ 优缺点

✓ 优点

  • 零额外参数，只在 Q/K 上做旋转，几乎不增开销。
  • 绝对形式、相对效果，兼得两家之长。
  • 对高效推理友好：旋转可直接施加到缓存的 K 上。
  • 可外推的底座：改一下频率基 (base θ)，就能把上下文往长拉——这正是 长上下文外推 的立足点。

✗ 局限

  • 直接外推仍会衰减：远超训练长度时，高频维旋转"绕圈"太多，注意力失真——需要 PI/NTK/YaRN 修正。
  • 只作用在注意力里，不改变 Value 表示。
  • 频率基、维度分组等超参对长文本效果敏感，需要调。

⑥ 被哪些模型使用（今日主流全景）

RoPE 几乎"通吃"了开源生成式大模型：

  • LLaMA 全系（1/2/3）、Qwen 全系、Mistral / Mixtral、Gemma、Falcon（团队实测 RoPE 优于 ALiBi 才选它）、GPT-NeoX、PaLM、ChatGLM/GLM（2D RoPE）。
  • DeepSeek V2/V3：因为用了 MLA（低秩压缩 KV）与旋转会冲突，特意设计了解耦 RoPE（decoupled RoPE）——单开一条只带旋转的小分支承载位置信息。见 模型×方法矩阵。
👉 为什么大家都选它
RoPE 把"相对位置该有的好处"用最省的方式（旋转、零参数、缓存友好）实现了，还留了一个可调的频率基当"长上下文旋钮"。这套性价比在 2023 年后的大模型军备竞赛里几乎无可替代。
➡️ 另一条现代路线
RoPE 之外，同年还有一个更"极端简约"的答案：ALiBi——干脆不加任何位置向量，只在注意力打分上按距离线性罚分。它的外推能力尤其出名。
