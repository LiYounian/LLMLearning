2018 Shaw · 2019 Transformer-XL · 2020 DeBERTa

相对位置表示 Relative Position

换一个提问方式：与其告诉模型"你是第 5 号、你是第 8 号"，不如直接告诉它"你俩相距 3"。把相对距离 i−j 注入注意力打分——这更贴合语言，也天生对"整体平移"免疫。

被这些模型使用： Shaw et al. 2018 Transformer-XL XLNet DeBERTa

① 核心思想：位置作用在"pair"上，不在"单点"上

绝对编码把位置贴在每个 token身上。相对编码则认为：真正重要的是两个 token 之间的距离。于是位置信息不再加到输入向量里，而是在计算注意力分数 qᵢ·kⱼ 时，额外注入一个只依赖 i−j 的项。

🔑 为什么"相对"更合理
"the cat sat on the mat" 不管整句在文档里是第 1 行还是第 1000 行出现，词与词的关系不该变。相对编码对整体平移不变：把整段话往后挪，所有 i−j 不变，注意力也不变。绝对编码做不到这点。

② Shaw 2018：给 Key / Value 加一个"距离向量"

最早的系统方案（Shaw et al.）。在注意力里，除了内容对内容，再叠加一个可学习的相对位置向量 a，按 i−j 索引：

eij = qi · ( kj + ai−jK ) / √d 同理 Value 侧也加 ai−jV。相对距离被截断在一个窗口 [−k, k] 内（太远的都归一类），既省参数又够用——毕竟"距离 100 和 101"的差别可以忽略。

③ Transformer-XL 2019：把注意力打分拆成四项

为了配合它的段递归机制（跨片段建模长文本），Transformer-XL 把 qᵢ·kⱼ 展开、并把其中的绝对位置项换成相对版本，得到四个可解释的部分：

(a) 内容↔内容：  Exi·Exj   （这个词和那个词本身搭不搭）
(b) 内容↔位置：  Exi·Ri−j  （这个词偏好距离多远的邻居）
(c) 全局内容偏置：u·Exj
(d) 全局位置偏置：v·Ri−j  （对某些相对距离的普遍偏好） R 是（正弦式的）相对位置编码，u、v 是可学习的全局向量。核心变化：原来含"绝对位置 j"的项，全部替换成"相对距离 i−j"。

④ DeBERTa 2020：解耦注意力（disentangled attention）

DeBERTa 把"内容"和"位置"彻底拆成两套向量，注意力分数由三类交互相加：内容↔内容、内容↔位置、位置↔内容（它论证"位置↔位置"贡献很小可略）。相对位置在这里是一等公民，配合它的效果在当年多个榜单登顶。

⑤ 它解决了什么、代价是什么

✓ 优点

  • 平移不变：更符合语言本质，长度泛化通常优于绝对编码。
  • 不占绝对长度上限：距离截断后，超长序列也有对应的相对桶。
  • 可解释：注意力被拆成"内容/位置"清晰的几项。

✗ 局限

  • 更复杂、更慢：注意力多出若干项与索引，工程实现比"加个向量"重。
  • 早期实现对 KV cache / 高效推理不够友好。
  • 形式多样、各家不一，不如后来的 RoPE/ALiBi 统一简洁。

⑥ 被哪些模型使用

Transformer-XL、XLNet、DeBERTa、Music Transformer 等是相对位置的代表。相对位置这条思路影响极深：它提出的"位置应作用在 token pair 的注意力上、且只关心相对距离"，正是后来 RoPE 和 ALiBi 的共同出发点——只是它们用更优雅的方式（旋转 / 线性偏置）实现了同一目标。

➡️ 下一步：能不能再简单点？
Shaw/XL 的相对编码要给 Key、Value 都加向量，还挺重。T5 把它砍到极简：只给注意力打分加一个标量，还跨层共享。
