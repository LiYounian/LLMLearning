学习式绝对位置嵌入 Learned Absolute

比正弦编码更省事的思路：位置也做成一张可学习的向量表，第 i 个位置就查表里第 i 行，加到词向量上。简单、直接、好训——代价是序列长度被钉死在训练上限。

被这些模型使用： BERT / RoBERTa GPT-1 / 2 / 3 原始 ViT

① 核心思想：位置就是一张查找表

词有词表（token → 向量），那就再给位置也建一张表。预设最大长度 L（比如 512、1024、2048），初始化一个 L×d 的矩阵 P，第 i 行就是"第 i 个位置"的向量，和词向量一起参与训练、被梯度优化：

输入i = 词向量(tokeni) + P[i] P ∈ ℝL×d 是可学习参数。和正弦版唯一的区别：正弦版的 PE(i) 是算出来的固定值，这里的 P[i] 是训出来的自由参数。

不用手工设计任何函数，模型自己学"每个位置该长什么样"，只要对下游任务有利。BERT、GPT 系列、原始 ViT 都用这一招。

② 它相对正弦编码好在哪

  • 任务自适应：位置向量由数据驱动，直接朝"降低训练损失"的方向优化，不受人工函数形式约束。
  • 实现极简：就是多一张 embedding 表，和词嵌入同构，工程上零心智负担。
  • 短序列上表现好：在训练长度范围内，效果通常不输甚至略胜正弦编码。

③ 致命短板：长度被钉死，不能外推

🚧 只有 L 行，第 L+1 个位置没有对应向量
表是 L×d，一旦推理时序列超过 L，第 L 行之后根本不存在——模型没有任何东西可查。这就是为什么 BERT 的输入被硬限制在 512 token、GPT-2 在 1024、GPT-3 在 2048。想变长只能重新训练更大的表。

✓ 优点

  • 数据驱动、任务自适应，训练长度内效果好。
  • 实现最简单，与词嵌入完全同构。

✗ 局限

  • 硬长度上限：超过 L 无编码可用，无法外推。
  • 占参数：长序列 = 大表；且每个位置独立学，位置 511 与 512 之间没有内建的"平滑/邻近"关系，全靠数据学。
  • 仍是绝对位置，相对关系要模型自己悟。

👉 一个观察
早期编码器 / 早期 GPT 偏爱 learned absolute；但它"不能变长"的硬伤，在大模型追求长上下文的年代越来越刺眼。这直接推动了两条新路：把位置改成相对的（更符合语言直觉），以及用旋转 / 偏置让位置天然可外推。
