历代方法总览

分词的历史，本质是围绕一个权衡曲面反复腾挪的历史：词表大小 ↔ 序列长度 ↔ 覆盖率(OOV) ↔ 语义。四个目标不可能同时最优，每一代方法都是在这个曲面上换了个落点。

① 权衡曲面：一切方法的坐标系

先记住这四个互相拉扯的量，后面每种方法都可以定位到它在这个曲面上的位置：

  • 词表大小 → 决定 embedding 表和输出 softmax 的成本。想要小。
  • 序列长度 → 注意力是 O(n²)。想要 token 长（一句话切出的 token 少）。
  • 覆盖率 / OOV → 任何输入都要能表示。想要无未登录词。
  • 语义 → token 最好≈有意义的单位（词素/词）。想要强。
🧭 一句话
词级把语义拉满但覆盖率/词表崩了；字符级用极小词表换来零 OOV，却牺牲了语义和序列长度。subword 就是被谈判出来的中间地带——今天几乎所有 LLM 都站在这里。

② 词级（word-level）：word2vec / 早期 NMT 时代

做法：按空格/标点切，每个不同的词就是一个原子 token。取语料里最高频的 V 个词（NMT 常见 3万~8万），其余全部映射成 <UNK>。是 word2vec[a]、早期 seq2seq 翻译[b] 的默认方案。

三个连锁死穴：

  • OOV 崩塌：任何没见过的词（人名、数字、新词、错字、URL）都变成一个毫无意义的 <UNK>，信息直接丢失。
  • 稀疏 / 长尾：词频服从 Zipf 定律，大部分词只出现一两次，embedding 学不动。而且 run/runs/running 是三个毫不相关的 ID——词形变化对模型完全不可见。
  • 词表又大又不全：V 越大，softmax 成本越高（NMT 里 softmax 是主要开销），却永远覆盖不全——构词是无限的。

还有个隐性负担：中文/日文/泰文没有空格，得先上一个独立的分词器（jieba、MeCab）做预处理。

③ 字符级（character-level）：矫枉过正的另一极端

做法：词表 = 所有字符（或 256 个字节）。任何字符串都是这些原子的序列，天生零 OOV，且不需要训练。

优点缺点
字符级 词表极小、零 OOV、语言无关、无需预分词 序列很长（约词级的 4–5 倍，O(n²) 吃不消）；单字符几乎没语义，"字符→词素"的活全甩给模型自己学

相对词级：用语义和序列效率，换来了彻底的零 OOV 和极小词表。subword 就是为了坐到这两极中间而发明的。

④ Subword 革命（2016 起）：坐进甜点区

核心洞察：常用词整体成一个 token（高效、有语义），罕见词自动拆成已知的更小片段（零 OOV、不丢信息）。切分粒度不再人工规定，而是从语料统计里学出来。三条技术路线：

路线 A

BPE（自底向上·频次）

反复合并最高频的相邻对。GPT/Qwen/DeepSeek 的算法底座。→ 详见第 03 节

2016 Sennrich
路线 B

WordPiece（自底向上·似然）

BERT 用。不按频次、按"似然增益"合并。→ 详见第 04 节

2012 / BERT
路线 C

Unigram（自顶向下·剪枝）

反着来：从大词表 EM 剪枝。T5/LLaMA 系相关。→ 详见第 04 节

🎯 主线（务必记住）
词/字符是两极；BPE、WordPiece、Unigram 是中间地带的三种算法；SentencePiece 是让这块中间地带变得"语言无关 + 可无损还原"的工程框架。之后 GPT-2 又把 BPE 挪到字节上（第 05 节），奠定了今天的主流。
