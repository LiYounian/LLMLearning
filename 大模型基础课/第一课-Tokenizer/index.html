Lesson 01 · Tokenizer

Tokenizer 的工作原理

从单个字符，到词片（subword），再到字节流——大模型是如何把人类文字切成一个个 token，又是如何统计、编码、还原的？本课把历代分词方法讲透，并对比 GPT / Qwen / DeepSeek / Kimi 等主流模型的真实做法。

🧭 一条主线
词（word） → 字符（char） → 词片（subword：BPE / WordPiece / Unigram） → 字节（byte-level BPE） → 动态字节块（frontier）。 每一步都在解决上一步的痛点。这条线看懂了，你就理解了今天所有主流大模型分词器的来龙去脉。

📜 分词技术演化时间线

1994

BPE 作为压缩算法诞生

Philip Gage 提出字节对编码，本是一种数据压缩方法，与 NLP 无关。

~2013

词级时代

word2vec / 早期神经机器翻译用固定词表，饱受 OOV（未登录词）与超大词表之苦。

2016

Subword 革命：BPE 进入 NLP

Sennrich 等把 BPE 引入机器翻译处理稀有词，开创 subword 时代。

2016 / 2018

WordPiece 与 Unigram

WordPiece 支撑 BERT；Kudo 提出 Unigram LM 与 SentencePiece 框架，语言无关、可逆。

2019

字节级 BPE（GPT-2）

在 256 个字节上做 BPE，彻底消除未知字符，成为此后生成式大模型的主流范式。

2021

tokenizer-free 探索

ByT5 / CANINE 直接吃字节/字符，追求"无分词器"的未来。

2023–2026

词表越做越大 & 动态分块

GPT-4o 词表冲到 ~20 万；同时 MegaByte / BLT 用动态字节分块重新挑战"要不要分词器"。
