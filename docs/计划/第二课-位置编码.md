## 一、课程目标

讲透"大模型如何把**顺序信息**注入 Transformer"。一条主线贯穿：

> **绝对位置**（给每个位置一个编号/向量）→ **相对位置**（只关心 token 间距离）→ **RoPE / ALiBi**（把相对位置融进注意力，成为今天主流）→ **无位置编码 NoPE**（反思：真需要吗）→ **长上下文外推**（训练短、推理长怎么办）。

看懂这条线，就理解了从 2017 原始 Transformer 到今天 LLaMA / Qwen / DeepSeek 长上下文模型的位置编码演化。

设计沿用第一课观感：深色主题、时间线首页可点击节点、每个方法标注"被哪些主流模型采用"、关键处配交互动画、每条结论对应一手来源。

## 二、方法时间线（首页节点，按进入视野年份排序）

| # | 页面 | 年份 | 方法 | 一句话 | 代表模型 |
|---|------|------|------|--------|----------|
| 1 | p1-why | 2017 | **背景：为什么需要位置编码** | 自注意力是"集合运算"，对顺序不敏感（置换等变）；不加位置信息，"猫追狗"和"狗追猫"没区别 | —（原理页） |
| 2 | p2-sinusoidal | 2017 | **正弦/余弦绝对位置编码 Sinusoidal** | 用不同频率的 sin/cos 给每个位置一个固定向量，无需训练、可外推 | 原始 Transformer |
| 3 | p3-learned | 2018–2020 | **学习式绝对位置嵌入 Learned Absolute** | 位置当成可学习的 embedding 查表，简单有效但不能超过训练长度 | BERT / GPT-2 / 原始 ViT |
| 4 | p4-relative | 2018–2019 | **相对位置表示 Relative** | 注意力里加入"两 token 相对距离"的可学习偏置/向量 | Shaw 2018；Transformer-XL；DeBERTa |
| 5 | p5-t5bias | 2019–2020 | **T5 相对位置偏置** | 极简版相对位置：给注意力打分加一个"按距离分桶"的标量偏置，跨层共享 | T5 / mT5 |
| 6 | p6-rope | 2021 | **RoPE 旋转位置编码** ⭐ | 用旋转矩阵把位置角度"乘"进 Q/K，内积天然只依赖相对距离；今天开源大模型绝对主流 | LLaMA 全系 / Qwen / DeepSeek / ChatGLM / Mistral / Gemma |
| 7 | p7-alibi | 2021 | **ALiBi** | 不加任何位置向量，直接在注意力打分上按距离线性衰减惩罚；外推能力强 | BLOOM / MPT / (部分) Falcon |
| 8 | p8-nope | 2023 | **NoPE 无位置编码** | 研究性结论：因果掩码本身就泄漏了位置信息，decoder-only 不加显式位置编码也能学到顺序 | 研究前沿（非旗舰生产默认） |
| 9 | p9-extrapolation | 2023–2024 | **长上下文外推：PI / NTK / YaRN / LongRoPE** ⭐ | 训练 4K、推理 128K 怎么办？在 RoPE 频率上做插值/缩放，把上下文"拉长"而不重训 | LLaMA-2 Long / CodeLLaMA / Qwen / 众多长文本模型 |

> 时间轴上把 RoPE（p6）和长上下文外推（p9）标为重头戏（era/frontier 样式高亮），对应第一课里 BBPE / tiktoken 的地位。

## 三、每页结构（统一模板）

复用第一课的方法页骨架，每页至少含：

1. **面包屑 + method-head**：年份徽章 + 标题 + lead 一句话 + `被这些模型使用` 徽章行。
2. **核心思想**：直觉先行，一段话说清"它想干嘛"。
3. **数学形式**：给出公式（用行内 `code`/`pre` 排，配一个直觉解释或小图），不堆符号、每个符号都解释。
4. **解决了上一代什么问题**：承接时间线，明确"痛点 → 这一招"。
5. **优缺点**：`.note` 提示框，正反两面。
6. **被哪些主流模型采用**：小表格 / 徽章，存疑处显式标注"未确证"。
7. **可交互 demo**（部分页，见下）。
8. **pagenav**：上一节 / 下一节串成线。

## 四、交互 demo 清单（vanilla JS + canvas/SVG，沿用第一课 `init函数` 模式）

| 页面 | demo | 交互内容 |
|------|------|----------|
| p1-why | **置换不变性演示** | 打乱一句话的 token 顺序，展示"无位置编码时注意力输出不变"的直觉（简化示意） |
| p2-sinusoidal | **正弦编码热力图** | canvas 画 位置×维度 的 sin/cos 编码热力图；滑块调维度/序列长度；点某位置看它的编码向量 |
| p6-rope | **RoPE 旋转可视化** ⭐ | 2D 平面上一对向量随位置角度旋转；展示"两向量夹角只依赖相对位置差"；滑块调位置 m、n |
| p7-alibi | **ALiBi 衰减斜率** | 不同 head 的斜率 m 下，注意力偏置随距离线性衰减的曲线；滑块调 head 数 |
| p9-extrapolation | **外推行为对比** ⭐ | 对比 原始 RoPE / 位置插值 PI / NTK-aware / YaRN 在超出训练长度时的频率-位置映射曲线，直观看"谁把上下文拉长了" |

> demo 本地静态服务打开验证 JS；做不动的用静态 SVG 兜底，不留坏交互。

## 七、事实核对策略（铁律：查证、标一手来源、没把握就注明）

动手前对以下逐条查证一手来源，写进 references 并在正文标注：

- Learned absolute 的采用（BERT / GPT-2 / ViT 各自论文）。
- Relative 的两支（Shaw et al. 2018；Transformer-XL 2019；DeBERTa 解耦注意力）。

- ALiBi（Press et al. 2021）与 BLOOM / MPT 采用。

- 外推四法：Position Interpolation（Chen et al. 2023）、NTK-aware（社区/kaiokendev + reddit 起源，注明非正式论文出处）、YaRN（Peng et al. 2023）、LongRoPE（Ding et al. 2024）。
